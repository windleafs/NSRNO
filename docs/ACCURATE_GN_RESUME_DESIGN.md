# 在原固定Gauss–Newton问题上准确续算

真实CPU续算已将同一近似子问题的相对KKT由0.422292降至0.00768534，
追加160次迭代、132.15秒，新增患者传播和GPU计算均为0。100次固定CPU
预算不足这一点已有实际证据，不能以这些未解好的步骤判断数据可辨识性。

新入口resume_native_gn_accurate.py只在源作业结束、RF/图像已保存、源PID
和工作PID均退出后启动。它重建原固定材料处的g、TV度量、阻尼和BFGS
模型，复用全部已保存HVP，不重算梯度或旧方向。恢复时需再现原二次
目标、阻尼与TV二次量。新CPU候选必须满足1%相对KKT再执行新HVP，
CPU最多1200次并保存检查点；未达目标就保留状态并结束该作业，不能
把未收敛候选当作精确方向。

原生真实二次问题的目标仍为原定0.1%相对KKT。本次最多增加8次HVP，
达到预算时报告实际残差，不声称QP精确收敛。每次新的真实HVP用于
确认可行线段下降，并继续保存完整方向、数据像、总像、累计u/Hu。
固定线性化材料与已接受的物理材料分别记录，二者不能混淆。

最终每个材料候选由真实RF回溯判断，既要满足相对固定参考材料的
Armijo条件，也必须优于源作业已经接受的实际材料。不能仅相对较旧
基线下降却让当前物理结果变差。绘图比较的初始值使用源已接受材料。
若没有新的真实二次步骤，不重复原有物理回溯。

保存来源路径清单，后续可在同一固定模型上继续恢复全部方向。全部
原生像素的c/rho/组织alpha保持独立，观测仍为完整11平面波+11点发射、
192接收及原保留RF，单卡16GiB限制继续。低秩数组位于CPU。图像只有
在物理回溯后作独立事后评价，真值不参与优化。

这一修改是补足已有数值求解，并非新物理信息的证据。最终仍必须得到
有用三参数图，并通过独立衰减配对和其他病例的实际重建；原目标未完成。
