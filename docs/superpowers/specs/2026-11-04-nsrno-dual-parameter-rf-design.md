# NSRNO 乳腺双参数全波形反演设计稿

日期 2026-11-04

## 研究问题

固定 V5 乳腺数据的单侧平面波采集后，真实 RF 是否足以在指定空间尺度上区分声速与密度变化？如果可以，可微神经正演能否在保持真实失配下降和参数恢复质量的条件下，减少反演耗时？以声速 c 和质量密度 ρ 为独立变量，输出可压缩率 κ = 1/(ρc²)。

代码、配置、派生清单和实验输出均置于 `/home_nvme/zhuangyang/nsrno`。V5 缓存作为只读数据源，用于确定样本范围、既有划分和声速标签对照。训练和反演通过 NSRNO 自有读取器、模型及初始化执行。全波正演使用独立的 UltraWave 工具链。

## 数据与已完成的核查

- 基础缓存 `/data/zhuangyang/geometry_flow_v2_cache` 有 600 条，原划分为 480／60／60。600 条均找到原始 NPZ 和对应分片，原始数据目录为 `/data/zhuangyang/NumerialBreastPhantoms/l11_ultrawave_500_11angle`。其中原始组织样本 500 条，高回声圆形干预样本 100 条。
- 补充缓存 `/data/zhuangyang/geometry_flow_v2_decv4_cache` 有 480 条训练变体。通过两个原始索引定位 480 个 RF 分片。`/data/zhuangyang/tmp/decoupled_root` 含 cswap、reseed、texture 各 120 条，`/data/zhuangyang/tmp/calib_root` 含 calibhom、calibuni 各 60 条。补充样本按原始索引的 source_id 继承病例与切片分组。上线前逐条检查身份、配对及元数据。
- RF 形状为 [发射角, 接收阵元, 时间] = [11,192,2401]。平面波角度 −8° 到 +8°，阵元间距 0.2 mm，采样 40 MHz，处理频带 4–7.5 MHz。观测定义为求解压力减去固定均匀参考，再按原流程带通并重采样。绝对时钟、发射参考时间、带通与采样都属于观测算子。
- V5 缓存包含复数 DAS 与 128×160 声速标签。600 个基础标签的缓存清单均标记为 legacy_index_resize。精确物理配对使用原生介质和坐标。原始文件的 216×192 的 m 是经高通和归一化的对数声阻抗派生量，ρ 单独从原仿真介质重建。
- 已用原始 HDF5、切片编号、随机种子和生成器恢复 train_000 与带高回声干预的 train_400。两者原生介质网格均为 [z,x]=[961,1121]，导出的 c、m 对照存档最大绝对误差均为 0。这个检查验证了两条标签重建路径，后续仍须用 RF 复演验证密度、衰减、采集与处理的整体一致性。

## 数据接口和网格

独立清单逐条记录 V5 缓存文件、原始 RF 或分片、父样本、病例、物理网格、生成器版本及散射随机种子。角度、时钟、增益、带通及归一化配置按记录校验。基础样本优先读取原始 NPZ，补充样本读取保存 RF 的分片。形状、坐标、单位、身份或来源不一致的记录单独列出并从训练清单隔离。以只读方式使用源文件，派生数据单独版本化。

保留 50 μm 的 UltraWave 传播网格与完整仿真域。首版在实际坐标上定义约 48×60 的反演参数网格，用固定插值将对数扰动嵌入物理区域，分别取 u=log(c/c_ref)、v=log(ρ/ρ_ref)。正演输入包含拼装后的完整介质、发射条件，以及实验明确允许使用的固定衰减场。区分待反演的低空间频率密度与已知或未知的亚分辨率散射纹理。全波基线和代理使用同一个空间支撑、参数范围、采集算子及对照初值。

在已知背景的控制实验中，可固定真值生成时的细尺度纹理、外域和衰减，用于测定给定条件下的局部信息量。独立的 V5 完整反演使用预先声明的均匀或平滑背景，使用训练数据确定的衰减设定。报告从参考到真值的参数投影误差、纹理及衰减模型差异引起的物理残差。区分已知背景的局部恢复与未知背景下的全图恢复。

## 竞争路线与模型

1. **物理正演和物理梯度。** 使用原采集 UltraWave 全波正演。第一轮在有限个可解释的空间基底中，用中心差分计算物理雅可比，在相同基底上做阻尼 Gauss–Newton 和局部 oracle 对照。全网格阶段需要通过内积和方向导数检查的物理伴随或等价可微求解器。物理基线优先回答采集信息是否足以恢复目标参数。
2. **纯神经正演，作为首选代理。** 多尺度介质编码器处理 c、ρ 和已知衰减，保留细尺度密度分支。共享的发射条件编码器使用 sinθ、cosθ 和参考时钟。坐标条件接收解码器按阵元和频率预测复谱，经共轭对称逆变换得到带符号 RF。频率表示通过存档 RF 的重建误差验证，选择使误差低于最弱预定物理扰动响应的表示。第一版使用固定的训练集尺度和有符号 RF 损失，评估时分深度窗和角度报告相位、时移、幅值及 RF 误差。用简单的参考场输出作为对照，检验模型是否使用了输入介质。
3. **物理切线加可学习非线性修正。** 在可复现参考介质附近，用 F_phys(m_ref)+J_phys(m_ref)δm 预测波形，网络学习余项。先用已经生成的成对全波扰动检验线性项的有效半径，再比较余项模型与纯代理的真实下降及耗时。若纯代理波形精度足够但导数偏离，比较方向导数监督与物理切线修正。若真实切线本身无法区分两类材料扰动，优先报告可恢复的参数组合与空间尺度。

纯代理训练后冻结。反演目标为 Φ(m)=½∥W(F(m)−g)∥²+λR(m)，W 和 R 在比较前固定。代理自动微分更新 c、ρ，两组梯度分别记录。初始化使用均匀或预先定义的平滑模型。代理的物理复核周期、回退规则与各阶段耗时单独记录，区分纯代理与经物理复核的混合算法。

## 先导实验和判据

1. **复演与参数覆盖。** 先选基础原始、高回声、cswap、reseed、texture、calibhom、calibuni 各一条，检查原生标签和采集参数。重跑零扰动，报告全 RF 和分角 RF 相对误差、时钟误差以及复演误差占最弱目标扰动响应的比例。拟要求后者低于 10%，并用步长减半检查中心差分的稳定性。失败时逐项比较介质、参考场和 RF 处理，暂停将该变体用于物理监督。
2. **信息量与双参数交叉误差。** 在同一留出仿体上，用固定 c 改 ρ、固定 ρ 改 c、两者独立变化三组真实全波对照。扰动从均匀、低频空间模态和局部扰动开始，并加入从均匀／平滑初值到真值之间的候选态。以等相对幅度的 log c、log ρ 为单位，检查白化雅可比的奇异值与列相关性。在明确的噪声水平下，比较可分离方向与近零响应方向，并报告 c→ρ、ρ→c 的串扰。用近真值和粗初值的结果差异区分局部信息不足和优化失败。随后比较固定与扰动衰减／纹理条件，测量这些变量能解释多少相同的 RF 变化。
3. **波形及导数。** 用相同基底和固定 W 对比代理自动微分 JVP 与真实全波中心差分。每类方向报告余弦、相对误差和增益比，并和物理参考误差比较。建议先导判据为有效方向的余弦中位数至少 0.9，JVP 相对误差中位数至多 0.3，同时逐类报告失败率。数值判据在训练及最终评估前锁定。
4. **真实下降和恢复。** 对每个候选更新方向，用真实求解器测量步前及步后失配。相同初值、可行域、正则化和停止规则下，比较物理基线、纯代理及必要时的物理切线修正。报告真实 RF 失配、c／ρ／κ 误差、反事实串扰及实际耗时。若代理损失下降而真实损失反复上升，即使前向 RF 指标合格，也判该代理的反演方向失效。加速比较计入候选复核成本，并单列训练与数据生成成本。

## 划分、实施顺序和结论范围

原验证集与训练集共享 Neg_07_Left、Neg_35_Left 两个病例。开发阶段在这两个病例之间交换训练／验证角色，变体随父样本分组，角度和同病例切片不跨角色。定稿后才用 Neg_47_Left 的 60 条原测试记录；结果属于一个独立病例。用训练病例生成的反事实验证模型选择，用独立病例生成的反事实检验参数分离。

按顺序实现独立数据读取和追溯、全波零扰动复演、受控双参数物理实验、代理训练和双轨反演。首批全波计算量由复演的实际耗时估计，优先覆盖两类独立扰动与有判别力的混合方向。低维先导只能回答所测子空间的问题。完整目标还需要约 48×60 网格、独立变化和未知背景下的物理失配及参数误差证据。若物理基线仅在已知纹理或衰减下成功，优先检验未知散射与衰减所形成的参数混淆，再决定估计哪些参数组合。
