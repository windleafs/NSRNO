# 观测 RF 相干聚焦初值的实际结果

本次只处理已有 `train_200`（开发病例 Neg_35_Left）发散波 3 MHz RF，没有生成新数据、没有 PDE 传播、没有材料导数实验，没有读取材料真值。执行 PID 1357704 已正常退出，输出 `out/v5/coherence_initialization_v1_train_200`。

53 个速度的二维注册与聚焦实际用时 11.461 s，显存峰值 0.19932 GiB。全局选中 1530 m/s，主相干指标 0.0027783077；1540 m/s 的对应指标为 0.0027625277，提升仅 0.5712%。达到最高指标 95% 的速度范围为 1510–1555 m/s；这是目标曲线的宽度，不是统计置信区间。

三个名义到达区域的峰值为 1535、1520、1465 m/s；各自达到最高指标 95% 的范围分别为 1515–1555、1500–1555、1420–1540 m/s。尤其深层曲线宽，不能将 1465 m/s 解释为可靠的局部声速。聚焦速度是路径量，还存在回波注册、有限孔径与非均匀传播的影响。

因此没有把 1530 m/s 写入正在运行的材料场，也没有据此再启动一组完整反演。单一全局声速偏差不是本次观测相干目标指出的有力修正方向。这个局部结论不能排除空间变化的声速初值或反射走时层析的作用；也不能证明数据不可辨识。

正在进行的自洽相位差初始化仍按原计划更新完整原生 c 场，随后释放 c/Z/alpha 拟合完整 RF。最终仍必须检查三参数的实际空间对比。
