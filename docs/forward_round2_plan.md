# NSRNO 第二轮训练

用户已确认：继续纯神经正演；先修正残差输出与损失的尺度匹配，再对同一架构充分训练。

1. 将残差输出从单一全局幅值改为四个训练集时间窗尺度，保持数据、网络层、目标物理单位和逐记录归一化损失不变。旧检查点仍可加载。
2. 新训练上限为 200 轮，保持每条记录每轮两个轮换角度。每五轮计算固定训练子集和完整开发验证集的指标。训练子集覆盖 64 条基础记录，最终评估覆盖完整基础训练集。
3. 同时运行相同初始化与训练预算的全局尺度对照，区分训练长度与输出缩放的作用。仅使用 GPU 0、1。
4. 至少训练 80 轮；之后若固定训练子集的逐记录平衡损失连续 40 轮没有下降至少 0.0001，则提前结束该运行。验证集用于选择 best.pt，提前停止依据训练拟合程度。
5. 最后以全部 11 角报告训练和验证误差、各时间窗误差及相对平均波形的误差能量下降。保留完整日志、权重、配置、代码快照和结果说明。

判读：训练与验证都改善，说明当前纯代理已有有效进展；训练改善而验证不改善，转向泛化问题；两者均无改善，缩放与本次训练预算不足以解决停滞，再讨论全局耦合和高频表达。不得把阴性结果解释为所有纯神经代理不可行。
