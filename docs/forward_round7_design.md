# Round 7: conditioned physical operator and learned preconditioning

The original goal remains a differentiable c/rho-to-channel-RF forward surrogate for joint inversion. Round 6 separated iteration error from attenuation-model error. This round asks whether a learned preconditioner reduces wavefield error at fixed operator count and wall time when attenuation is explicitly supplied.

Inputs are native c, rho, known alpha, frequency, angle, and fixed acquisition/relaxation metadata. Alpha is held fixed when differentiating c/rho; eta = alpha*c/C0*eta_per_unit_alpha retains its prescribed c dependence. No smoothing of c/rho and no learned source response. The external native PML and crop/edge-padding reproduce the V5 solver. The finite observation endpoint forcing is omitted from inference; its residual discrepancy is measured against archived RF, not absorbed into trainable coefficients.

Two mechanisms considered: (A) a learned right preconditioner inside differentiable GMRES, minimizing converged-field and PDE-residual errors; (B) a learned wavefield initialization followed by fixed physics iterations. A changes the correction subspace for arbitrary residuals, whereas B amortizes the distribution of source solutions. A is the first experiment because its fixed point remains the same known equation and it can later precondition adjoints. B should be reconsidered if A only reduces local residual while leaving phase/receiver errors unchanged. They are not treated as independent evidence from hyperparameter tuning.

Use the same 48 paired IDs selected for the 3 MHz dataset (32 Neg07 training, 16 Neg35 validation), but original 7.5 MHz-source V5 RF. Frequencies: RF bins 270, 360, 420; angles: 0, 5, 10 (-8, 0, 8 degrees). Neg47 remains untouched. These are 48 slices/variants, not 48 patients. Reconstruct alpha from original recipes in a CPU process and require exact cached c/rho agreement. Homogeneous incident fields come from the explicit acquisition source, never from a material target. Generate converged teacher scattered fields to relative residual <=1e-4, with convergence receipts.

First training budget: 240 optimizer steps through 8 GMRES steps; extend only if held-out loss is still decreasing and timing permits a useful decision. Network: bounded complex input/output diagonal gains conditioned on c/rho/alpha/frequency and a shifted spectral Helmholtz inverse. No vanishing boundary taper. Loss: relative wavefield error plus relative equation residual, no direct RF fitting. Compare fixed and learned preconditioners at 8/16 iterations and measure full per-input setup/solve time. Report RF spectrum error to archived labels separately from error to teacher channels. Convergence stopping is based only on equation residual.

Necessary checks: explicit source against the previously captured homogeneous field; finite differentiable training step and both input gradients; full selected validation set at equal operator count and measured time. Do not repeat earlier identifiability experiments. The decisive falsifier is a lower training/PDE loss without held-out field or channel improvement. A successful result here is not proof of full-band RF accuracy, deep recovery, or joint inversion.

Implementation order: conditioned operator/source and alpha cache; source consistency; teacher generation; differentiable Krylov preconditioner training; held-out evaluation; save code, settings, metrics, and interpretation.
