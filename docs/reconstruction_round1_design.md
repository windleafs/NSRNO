User approved the proposed actual reconstruction and comparison figure. Apply the previously approved design without another approval gate. This is an inversion experiment with the existing round-7 network, not another forward-training or identifiability study.

Scientific question: does optimization through the current conditional neural forward model recover useful c and rho maps from RF? The experiment is one fixed independent development sample, train_200 (Neg_35_Left). Its actual cached RF is observed; known true alpha is explicitly supplied. No true c/rho, material teacher field, anatomical segmentation, or truth-informed initialization enters optimization. Neg47 is untouched.

First route: frozen 16-step differentiable neural forward; optimize two native-resolution log-parameter maps jointly from c=1540 m/s, rho=1000 kg/m^3. Fixed gel at z<=0; otherwise geometric support only, no tissue mask. Log c scale .06 and log rho scale .08 provide numerical coordinates. Box bounds c=[1400,1700], rho=[850,1200] are broad material constraints, not fitted to this case. Weak edge-preserving isotropic TV (0.002 in normalized coordinates) and weak L2 (0.0001) stabilize poorly observed directions without restricting c to a smooth spatial basis. No c/rho smoothing or anatomy from alpha is used for parameterization.

Alternative mechanism considered: optimize the same objective using converged physical forward and implicit-adjoint derivatives, eliminating finite-unroll errors. This would distinguish surrogate exploitation from deficiencies of the acquisition/objective, but requires an additional inversion implementation. First finish the requested current-model reconstruction, then evaluate its initial and reconstructed maps with the converged physical solver. ## Geometric correction during execution

The initial z>0 optimization allowed changes in known coupling gel. Inspection of the generator, without reading material truth, confirmed GEL_MM=1 and default roughness=0 with nonnegative outer surface relief. Thus all z<1 mm is known uniform gel. Preserve the original run as an unconstrained-gel control. The primary corrected reconstruction uses z>=1 mm as free support, keeps all other settings, and starts again from the same uniform maps in `reconstruction_round1_train_200_gel1mm`. The correction removes a nonphysical freedom near the receivers; no tissue segmentation or truth-derived spatial constraint is introduced. Both runs have a200-update budget and receive the same post-hoc physical/parameter evaluation. Current code supports --fixed-gel-mm0 for reproducing the original support and --fixed-gel-mm1 for the corrected support.
