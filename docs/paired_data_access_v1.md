# 后续独立材料反证的数据支持

本轮没有生成额外 RF，也没有运行新的声速/密度材料导数实验。当前三参数图仍未恢复，以下修改只为后续独立衰减配对和另一开发材料准备必要接口。

- `v5_observations.py` 只查找观测 IQ 与采集参数，不加载材料数组；基础缓存路径保持相同。已有独立衰减材料 ID 可选取 3 MHz 和 7.5 MHz 的全 11 角 IQ。
- `v5_materials.py` 单独用于教师生成与事后评价，支持已有基础材料和配对三通道绝对材料。优化器不导入这个模块。
- `TimeAcquisition` 和原始 UltraWave 复算通过同一观测查找函数读取数据；配对数据的弛豫参数与角度须与传播模型一致。
- 发散波教师生成器已支持配对材料和明确指定的三通道绝对材料。每次生成完成后追加记录并保留原记录；同一输出目录串行生成以保护共享参考。已有 RF 不覆盖，部分缓存的材料哈希须相同。

实际读取了基础 `train_200` 与 `train_00_alpha_minus` 的 LF/HF IQ 文件头，四者均为 `[11,2,192,640]`；配对材料实际为 `[3,961,1121]`。其 LF/HF 弛豫参数和 11 个角度与当前物理模型一致。独立材料加载模块未导入 Torch。所有修改的脚本已解析；没有把代码解析当作真实传播验证。
