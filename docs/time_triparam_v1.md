# 三参数联合重建：准确时域梯度与显存

当前仍未完成声速、密度、组织衰减的实际联合重建。纯通道 UNO 已有的失败证据保留；本轮改用准确离散物理梯度，目的是区分代理偏差、优化失败和观测本身的不可辨识性。

本轮没有调用 Geo-Flow 模型。新 CUDA 算子匹配 V5 原数据生成器的八阶交错差分、两弛豫衰减、吸收边界、源注入与接收时刻。完整观测的梯度由分段重算得到，长度 128 的波场段留在 GPU，其余检查点放 CPU。每个角度约需 5.28 GiB CPU 检查点。

已经执行的检查：

- 小网格与自动微分参考相比，正演相对 RMS 误差为 2.76e-7；声速、密度、衰减三种梯度的相对 RMS 误差分别为 7.97e-7、7.26e-7、7.97e-7。
- 第二个开发病例 train_200，原生 961×1121 网格、中央角度、完整 24001 时点：3 MHz 与原高频源的处理后 RF 相对 RMS 误差分别为 2.3316e-5、2.0699e-5。18–36 μs 内分别为 2.3880e-5、2.7028e-5。
- 采集矩阵与原带通、重采样、IQ 频谱投影处理的相对误差为 2.28e-8；矩阵乘法的转置用于回传。
- 完整网格同时扰动三个参数的方向导数：伴随 1.626452565，中心有限差分 1.626509795，相对误差 3.52e-5。检查采用响应差和双精度内积，避免两个约为 1 的目标值相减造成消去误差。
- 单角度低频正演 8.52 s、反向 22.02 s，PyTorch 峰值分配显存 4.20 GiB。实际两进程反演的首个完整目标计算中，每卡峰值均为 4.23 GiB；GPU 0 的已有任务未受操作。

这些证据支持“新物理正演及其材料梯度准确、显存可控”，尚不支持“三幅材料图已经可以恢复”。

当前运行目录为 `/home_nvme/zhuangyang/nsrno/out/v5/reconstruction_time_v2_train_200`，PID 473021。GPU 1、2 分担全部 11 个角度；每卡分配上限 16 GiB。每次 L-BFGS 线搜索都重新计算当前固定频带的全部角度目标，最优状态始终包括初值。四个阶段依次使用已有 3 MHz 数据的 1.5–2.6、1.5–3.3 MHz，再使用低频源完整保留的 RF 频谱，最后同时使用高低两种源的完整保留频谱。最终目标包含带通滤波器过渡带，不能把标称 4–7.5 MHz 截止当成数据的硬频谱边界。参数空间由 0.2 mm、0.1 mm 递进至原生 0.05 mm；最终三种参数均不限制为平滑场。

优化坐标是声速、声阻抗和组织衰减，密度由声阻抗除以声速计算。初始声速 1540 m/s、密度 1000 kg/m³、组织衰减 0.5 dB/(cm MHz^1.1)，只固定几何定义的耦合层和已知数值边缘吸收。真实材料不参与优化，材料图评价在独立模块中执行。损失在 0–8、8–18、18–36、36–60.025 μs 四个窗按观测能量归一化，权重为 0.25、0.35、0.35、0.05，不将晚期小能量直接等同为不可用。

首个完整目标值为 0.4945585；四个时间窗的低频相对 RMS 误差为 0.9848、0.9978、0.9988、0.9907。初始坐标梯度范数为声速 0.02867、声阻抗 0.20278、衰减 0.003948。这表明均匀初值首先主要沿反射幅度方向变化，不能据此宣称已经分离三参数。

首次被接受的材料更新使同一个完整目标由 0.4945585 降至 0.4556890；四个时间窗的相对 RMS 误差变为 0.9701、0.9289、0.9654、0.9785。此时声速仅在约 1539.85–1540.15 m/s 间变化，密度约 998.86–1001.19 kg/m³，远不足以说明材料已经恢复。它只证明准确梯度和固定完整目标的更新已实际执行并下降。

第二次被接受的更新将同一目标继续降至 0.2699189，四个时间窗误差为 0.8182、0.6360、0.7435、0.8648。旧目录 `reconstruction_time_v1_train_200` 保留这两次更新、参数和完整日志。为修正末阶段的频谱范围，已停止该自有进程，当前 v2 从其最佳参数继续；这次停止属于目标实现修正，不是实验失败。v2 记录恢复参数的路径与 SHA256，事后材料评价仍与最初均匀材料比较，不会把恢复点冒充均匀初值。

竞争路线包括准确频域隐式伴随、当前时域离散伴随、单频空间波场 UNO。当前优先时域路线，因为一次传播覆盖完整脉冲频带，并能去掉上一轮代理误差及每次频率批次目标变化。最可能推翻当前选择的结果是：完整 RF 目标可以持续下降，而三幅材料图仍明显错误；那时问题需要转向参数串扰、优化吸引域和材料先验，不能继续靠增加相同迭代来解释。

下一项有决策价值的结果是全部角度目标下降后的实际三幅图，以及原求解器对该候选材料的独立 RF 复算。持续目标保持 active。
