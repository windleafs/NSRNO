# 走时坐标的原生初值保持

当前目标仍是三参数空间重建。编码组完整 RF 目标在 32 次更新后由 0.26702 降到 0.13570，但密度相关系数为 −0.171，三幅图没有恢复。几何到达分区组仍在运行；本文件准备后续针对参数耦合的可执行选择，不预设它能成功。

## 竞争性机制

一条路线是当前固定物理位置上的 c、Z、alpha 独立细场。它能表示真值，但改变声速会改变所有细散射到达，密度必须同时移动散射位置以补偿。现有 Adam/L-BFGS 不直接表达这种相关变化。

另一条路线是走时坐标 ξ=1540∫dz/c，独立场取 c(ξ,x)、Z(ξ,x)、beta(ξ,x)=alpha*c/1540，再映射到固定物理网格传播。在连续一维法向压力方程中，Z、beta 的 ξ 分布决定主要响应；二维角度和横向传播仍含声速信息。这种坐标把反射走时与位置补偿直接写入参数变化，不限定最终声速为平滑场。现有准确二维传播和离散伴随不变。

第三条原理不同的候选是密度势或 Sobolev 梯度。连续频域用 p=sqrt(rho)*psi 可将密度梯度项写成 V_rho=.5*Delta(log rho)-.25*|grad log rho|²；均匀背景附近 deltaV_rho≈.5*Delta(delta log rho)，提示原始密度梯度对高空间频率更敏感。但直接以势重建密度还需要处理边界条件和离散算子误差，本轮不先实现它，也不以这个连续推导宣称现有离散数据不可辨识。

优先准备走时路线，因为已有可微映射和真实方向导数依据，且可以保持原物理数据模型。先前走时组使用点 GMM 并缺少新增发散观测；它在早期被保存停止，并未证明不带该先验、采用更丰富观测的走时方法失败。新选择不使用点 GMM。

## 必须解决的初始化问题

已有走时初始化先从 50 μm 物理场插值到 40 μm ξ 网格，再回到物理网格，曾产生最大约 0.35 m/s、1.8 kg/m³ 的变化。细散射对这些插值变化敏感，不能将其再次当作无害初始化。

本轮不改变传播或其导数，只改初始化：对当前单调坐标插值矩阵 B，求最小范数修正 delta = Bᵀ(BBᵀ)^−1(target-B*values)。每个物理采样只涉及两个 ξ 节点，50 μm 物理间隔大于可达 ξ 单元的物理长度，因此 BBᵀ 按列是三对角正定系统。先迭代校正 c 的坐标关系，再校正 Z 与 beta；目标材料来自已保存的 RF 反演候选，不使用真值。

校正后的 ξ 场用既有 raw 参数的细节残差保存，因此粗更新和最终细更新都保留初始原生散射。只用 CPU 场值比较检查初始化是否保持已有材料，不重复已完成的材料 RF 导数实验。若不能保持初值或越过物理界限，先修复初始化，不启动实际反演。

## 下一步判别

当前先完成几何组的完整 RF 和三图评价。如果它仍有明显声速–散射位置补偿、不能恢复密度，再在相同 RF、相同几何权重、相同原生初值下试走时坐标。不同之处是坐标变化机制，而非数据集、频率或点材料先验。任何正面结果仍需独立衰减配对及另一个开发材料，不能以坐标保持或一维等价性代替成像。
