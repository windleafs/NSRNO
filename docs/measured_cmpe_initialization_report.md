# 共同中点相位候选的实际结果与决策

当前候选没有给出可采用的声速初始化，更没有实现三参数重建。一次实际 32 步 CPU L-BFGS-B 用时 47.44 s、34 次完整相位评价，达到预设迭代预算而非数值收敛。总目标从 0.852133736 降至 0.797464571（6.42%），其中相位部分为 0.796727625。GPU 显存为 0，没有产生新 RF 或调用传播求解器，没有停止原控制或耦合反演。

全部 11 次点发射和 192 接收形成共同中点信号对，700 个焦点中 684 个有有效孔径覆盖。所有权重固定于初始观测，选取候选只用自身完整相位代价加弱修正 TV。材料真值只在运行结束后的独立评价和下述机制诊断中读取。

在深度 1–43 mm、横向 ±19.1 mm 内，c RMSE 从固定 RF 初值的 53.9031 增至 56.8907 m/s，相关性从 0.19463 变为 0.19294；声速标准差从 2.1836 增至 26.5428 m/s，但图中的空间位置仍错。均值从 1539.80 变为 1541.39 m/s，真值均值为 1514.62。rho 仅按固定 Z 的关系 Z/c 变化，RMSE 从 50.9009 增至 56.3298 kg/m³；alpha 完全未更新。因此既不应把变幅增长解释为声速恢复，也不应把 rho 的代数变化解释为密度识别。

在查看材料评价前，已经写明只有 c RMSE 至少下降 10%且相关性超过 0.5，才值得增加完整原求解器 RF 评分。两项条件均未达到；没有启动原求解器复算，也没有将此初值注入任何联合反演。

为区分有限迭代与相位近似失真，独立后验程序仅比较同一相位代价在三个固定时间场的值，不改变候选：

| 时间模型 | 相位代价，不含 TV |
| --- | --- |
| 原 RF 初值的直线路径积分 | 0.8521337360 |
| 已选错误重建的直线路径积分 | 0.7967276252 |
| 真值声速的直线路径积分 | 0.8543346417 |

真值在该目标下并未优于初值，反而高于错误候选。因此，单纯增加该目标的迭代次数没有充分依据。这一证据针对本次直线路径、有限窗口、稀疏发射与实际异质散射条件的组合；尚不能分辨折射/衍射、多次散射与有限窗口的各自影响，更不能推广为一般声速或三参数不可辨识结论。它也不直接否定其他 CUTE 或共同中点方法。

后验 CPU 计算实际用时 477.31 s。进程曾出现较高内核时间、启用透明大页及主机内存压力；准备了仅本进程禁用大页的包装器。但执行替换前发现原诊断已正常完成，保护条件直接返回现有结果：没有发送信号，没有重算，包装器未运行。不能声称大页是经对照实验证明的唯一原因。

当前决策：停止扩展这一近似相位候选，保留真实输出和反证；主线继续完整波动方程的三材料耦合求解。另已准备几何加权、双固定编码和正块预条件器的独立下一版代码，尚未运行。最强的主线反证仍是完整 RF 降低而三个场的组织分区和独立 alpha 变化持续不恢复；目前主线只有第一步接受图，还不足以决定整条路线。
