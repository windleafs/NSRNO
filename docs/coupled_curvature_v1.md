# 当前结论与耦合更新的实际准备

尚未实现可信的声速、密度、组织衰减三参数联合空间成像。完整耦合反演于 07:02 CST 启动，已接受前两步。完整 RF 数据项从 0.3394932663 降至 0.3090660782（降低约 8.96%），实际三图仍接近初值；第二步仅在 1/32 提议步长处接受。下文保留准备与设计变更的记录，以本段和末尾的接受结果为准；本文件不能被当作正面重建报告。

两种几何 RF 反演在相同的 64 次低频更新、32 次高频联合更新后，RF 数据项为 0.2932932（物理坐标）和 0.2962472（走时坐标）。c/rho/alpha 相关性分别为 0.2074/−0.1044/0.1615 和 0.2853/−0.0974/0.0821。实际同色标三图都仍接近均匀场，密度的组织对比未恢复。声速标准差只有 2.6585/3.5608 m/s，真值 48.0394 m/s；密度标准差 8.0546/7.7013 kg/m³，真值 49.5078 kg/m³。

这支持继续正在运行的相位初始化，同时准备从不同原理处理耦合曲率。它不能排除有限角观测、散射率位置与空间先验不足，也不能证明单侧三参数一般不可辨识。

## 方法设计与启动历史

`reconstruct_coupled.py` 使用原生全场 c/Z/alpha，GPU 只作传播和伴随，CPU 作矩阵自由 PCG。数据梯度、回溯及接受候选都使用全部 11 次发射、192 接收和实际几何 RF。近似正定曲率用包含全 11 发射的固定编码；其时间窗度量不同于几何目标，明确不宣称为精确几何 Hessian。最终保留完整原生细场，不规定三个材料共边界。

CPU 等待程序输出 `out/v5/reconstruction_coupled_v1_train_200/launch.json`，实际 PID 以该文件和进程句柄为准。它等待两组旧控制释放，检查每卡预留 5.75 GiB 加上下文后仍不超过 16 GiB、主机可用内存至少 32 GiB，再从固定 RF 初值启动 8 个外迭代、每次最多 8 次 PCG。它不自动停止控制组，也不重启既有反演。

相位组第 32 次完整评价：相位项由 0.08401394 降至 0.06755375，而完整 RF 项由 0.26941423 升至 0.30864366。声速 RMSE 53.9031→54.3486 m/s，相关性 0.1946→0.0970，空间标准差 2.1836→6.6353 m/s（真值 48.0394）。位置仍不正确，不能将变幅增长或相位项下降当作初始化成功。Z 和 alpha 在该阶段固定，alpha 逐元素完全不变；rho 随 Z/c 代数变化，不是独立密度恢复。

因此耦合组独立采用物理组完整 RF 选出的 3 MHz 第 64 次固定初值，和原物理控制高频阶段起点一致。相位组继续其阶段；不把这一尚未成功的相位初值作为两种方法共同前提。旧 CPU 等待进程 1419546 已因这个明确的初始化设计修改退出，新 CPU 等待进程为 1432050。替换前确认不存在优化 `workflow.json` 或 `run.json`，完整耦合反演没有因此重启。原等待记录保存在 `launcher_phase_superseded.json`。

原两控制仍在运行。计划在各自 64 次高频完整评价后，依据实际三图决定是否将剩余一阶更新预算转给耦合路线；尚未执行停止，不把 64 次预算等同于原计划 128 次完成或收敛。

新的后处理先输出最终三图；失败图不自动增加一次原始求解器复算。正面三图仍需要原求解器全发射复算、固定 c/rho 的独立 alpha 配对与另一开发材料，才能评价真实三参数恢复。最强反证是：耦合更新完整 RF 明显下降，组织尺度的三场对比仍不恢复，或密度和衰减只补偿声速错误。那时应优先处理反射率/边缘先验与观测耦合，而不是继续修改 Adam 步长。
