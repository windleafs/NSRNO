# 三参数反演：自适应匹配滤波候选

## 问题与已有证据

当前目标仍是 V5 乳腺的声速、密度和组织衰减空间重建。相同初值与相同 16 次更新下，走时坐标将声速相关性从物理坐标的 0.172 提高至 0.301，但其空间标准差仅 1.98 m/s，真值为 48.04 m/s；密度仍负相关，衰减主要恢复均值。现有物理坐标、走时坐标和完整 LF/HF 三组继续计算，尚未因这些中间结果被停止。

## 原理不同的候选与选择

1. 完整 RF、几何到达分区和物理坐标：保持现有精确二维传播及全部细场自由度；逐点波形误差可能仍陷入错误周期。
2. 同一 RF 目标、走时坐标：将声速变化与散射位置移动一起表达，改变参数空间中的搜索方向，不改变波形误差的局部极小值。正在实际比较。
3. 自适应匹配滤波：为每条预测与观测迹线构造一个匹配滤波器，以滤波器的能量集中在零延迟为目标；这是改变数据目标的路线，可在没有新增低频激励的情况下减轻时间错位造成的错误周期。
4. 频差构造：已有论文用高频之比初始化透射式 FWI，但本文反射、细散射和三未知量不满足其透射假设。这里不把频差数据当成新的物理低频 RF，不修改原传播来强行拟合它。

选择先准备候选 3。它保留精确原传播和伴随，只增加小型 FFT；待有计算资源且当前组完成有判别力的阶段，再决定是否运行。没有增加 GPU 工作进程，也没有改变正在计算的组。

## 具体目标

采用 reverse AWI：设 P、D 为预测及观测窗内 RF 的频谱，V=P*conj(D)/(|D|²+epsilon)，v=IFFT(V)。对每条接收迹线，使用

    J_AWI = 1/2 * [1 - sum(G(tau)*v(tau)^2)/(sum(v(tau)^2)+nu)]
    G(tau) = exp[-tau²/(2*sigma²)]。

频谱在两倍记录长度外补零；epsilon 为每条观测频谱最大功率的 10%，只依赖固定观测。第二版 nu 为观测自匹配滤波器能量的 1e-3，限制预测接近零时的梯度。零预测的集中度取零，目标为 1/2。nu 会引入很弱的幅度依赖，需在报告中明确。

沿用现有各发射–接收对的 5 个名义几何到达区间，边缘用固定短余弦平滑；各区间的权重与原几何组相同。窗内按观测迹线能量加权，并以全 11 发射的窗能量归一化。它们仍只是名义到达类，不是真实深度定位。最终全 RF 不被裁掉。

AWI 对整体幅度缩放近乎不敏感，单独使用无法确定密度和衰减。因此若初始化阶段同时释放三参数，需要加入完整 RF 幅度目标；也可在运动学初始化时固定 Z 和 alpha，只更新 c，然后在最终完整 RF 阶段释放全部三参数。不能把 AWI 自身下降视为三图恢复，也不把文献中与速度通过经验关系绑定的密度当成独立密度的证据。

## 时间移位结果驱动的实际修改

全部 11 发射、192 接收的 CPU 检查已完成。整体平移会将强表层回波移入弱分区，使几何 RF 目标异常增大，所以增加了更有判别力的设置：保留较早回波，只平移名义 12 mm 以后到达类的分量。这个局部信号操作仍不等于真实材料变化。

后一设置中，1–3 μs 区间原 RF 目标的正确恢复方向比例为 54.8%，AWI 为 100%。但 AWI 的自匹配惩罚为 0.05966，来自有限带宽与稳定化后的滤波器形状；因此进一步构造严格自洽的频率相位差目标。

设同一窗内精确预测的频谱为 P_k，观测为 D_k；取

    b(P)_k = P_(k+l) conj(P_k) /
             sqrt[(|P_(k+l)|²+q_D)(|P_k|²+q_D)]

其中 q_D 为固定观测频谱最大功率的 1e-3。将 b(P) 与按完全相同公式构造的 b(D) 比较，按固定观测频谱的成对功率及各接收迹线能量加权。在 P=D 时损失严格为零。若一条完整波形只发生时间移动 tau，频率间相位变化包含 exp(-i*2*pi*Delta_f*tau)；Delta_f=78.125 kHz，对应 ±6.4 μs 内的单调理想移位区间。

78.125 kHz 是现有 3 MHz RF 频谱中两个频率的间隔，不是新增发射中心频率，不是把频差当作真实低频波场。实际实现仍通过原始完整二维传播得到 P，再计算这一特征。

该目标在上述保留表层的移位检查中，也在 1–3 μs 区间获得 100% 正确恢复方向，自匹配惩罚为 0。零预测损失为 0.12228，非零整体缩放只引起小变化，说明它仍需最终 RF 幅度目标约束。

## 已实施、尚未运行的反演方案

`reconstruct_kinematic.py` 是独立实验脚本，未修改三组正在执行的对照。计划使用物理几何组完成第一阶段后、由完整 RF 选出的原生候选作为初值。

- 第一阶段 64 次：相邻频率相位差目标，只更新物理 c 参数；Z 和组织 alpha 保持输入值。由于 rho=Z/c，密度随 c 有代数变化，这不是固定物理密度。
- 第二阶段 128 次：加入原高频组，释放 c、Z、alpha 的全部原生细场，用完整 RF 几何目标联合反演。最终 rho=Z/c。
- 每一空间层的 c、Z、alpha 分成独立 Adam 参数组。初始化 c 学习率为 0.015；最终 c/Z/alpha 为 0.003/0.008/0.008。四层倍率为 1/1/0.5/1，细网格不再降到原来的 1/4。仅对梯度乘倍率会被 Adam 的归一化抵消，所以倍率作用于实际学习率。
- 所有阶段使用全部 11 发射的随机重排、所有接收；完整数据评价每 32 次一次。第一阶段候选由完整相位目标选择，最终候选只由完整 RF 加原弱 TV 选择；两者均不读取材料真值。
- 每工作进程预算 5.75 GiB；当前三个计算组仍占用资源，新方案等待原始 LF/HF 组及其独立复算释放显存。新方案的实际 GPU 峰值尚未测量。

实际三图与原始求解器复算将决定是否继续采用此初始化。时间移位曲线和自洽性不构成三参数联合恢复证据。

## 更新幅度的另一个可能障碍

旧设置中三个坐标共用 0.006/0.003，且细网格倍率为 1/4。在恒定梯度符号、忽略约束曲率的参考情况下，64 次余弦衰减的四层总原始坐标移动量约 0.64，对声速约 50 m/s、对阻抗约 6% 的对数变化；这不是一般 Adam 轨迹的严格上界，但说明优化预算也可能限制实际对比，不能把所有灰色图都归因于可辨识性或周期跳跃。

新配置使每个物理坐标具有独立的实际步长，并允许细场有足够更新幅度。它同时改变目标、更新次序和步长，不构成单一因素归因实验。最终仍保留原生 50 μm 三参数自由度、原弱 TV、相同物理传播和原始数据。是否能恢复组织对比必须由实际图像决定，不从步长算术推断成像成功。

## 最便宜的反证与资源

先只用真实 3 MHz 发散波的全部 11 发射、192 接收，把观测人为平移 ±4 μs，比较原几何 RF 与 AWI 目标。此处无需材料真值、无需新传播、无需新的物理材料导数检查。若 AWI 在 1–3 μs 错位上仍频繁产生方向错误的局部极小值，就不启动昂贵的反演；这能直接否定候选最重要的时间错位机制。

同时检查真实 RF 的 0.25/1/4 倍幅度缩放，明确显示其幅度盲区，以及加入 RF 后的约束作用。这个 CPU 检查只支持目标函数的时间错位性质，不能证明三参数可辨识或图像恢复。

新 FFT 仅处理当前单次发射；全部观测归一化固定，不随预测变化。实现时不缓存所有发射的 GPU 频谱，传播仍逐发射复用既有约 4.5 GiB 的状态带，单工作进程预算保持 5.75 GiB，单卡总显存仍需实测不超过 16 GiB。

## 文献与证据边界

- Warner & Guasch (2016), *Adaptive waveform inversion: Theory*, https://doi.org/10.1190/geo2015-0387.1 。本文借用 reverse 匹配滤波的零延迟集中机制；论文的密度随速度参数化，不是独立三参数恢复证据。
- Ali et al. (2025), *Frequency-differencing strategy to kickstart full-waveform inversion without cycle skipping*, https://doi.org/10.1121/10.0034763 。其透射应用不直接证明反射数据的频差是当前波动方程的真实低频观测。

任何实际新反演必须评价三幅图并经原 UltraWave 独立复算。若恢复出现，仍需要独立衰减配对与另一开发材料，最终留出不用于选择。
