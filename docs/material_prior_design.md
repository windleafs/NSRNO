# 与纯物理反演竞争的材料统计先验

当前原始目标仍是声速、密度、组织衰减的实际联合重建。已经执行的低频全角度更新降低了 RF 误差，但事后材料评价与均匀初值几乎相同；这不证明纯物理路线最终失败。当前物理反演继续运行，统计先验在 CPU 上独立准备。

机制候选：

1. 继续准确全波形 L-BFGS：依赖角度、频率和多次散射中的材料信息；不增加材料先验。若完整双源 RF 拟合准确而三幅图错误，单靠更多同类更新不能解决该问题。
2. 包络或频差目标：改变优化的吸引域，缓解相位周期导致的局部极小；它们都是现有 RF 的函数，不能在完整 RF 已相同的两幅材料之间创造新信息。作为 RF 无法拟合时的候选。
3. 材料统计先验加准确波形：从训练病例中学习三种参数的联合分布，对观测弱的背景方向提供约束；空间位置和最终数据拟合仍由观测决定。当前准备此项，保持与第一项分开的结果目录。

先验仅使用 Neg_07_Left 的训练材料，绝不读取 Neg_35_Left 开发病例来拟合。原始材料与现有独立三参数扰动材料共同采样，避免把衰减固定成声速和密度的确定函数。学习变量为 `(c-1540)/80`、`(rho-1000)/100`、`log(alpha_tissue/0.5)/0.7`，使用具有完整协方差的高斯混合模型。协方差加独立方差下界，保留三种参数各自的变化空间。

原始材料样本占约 75%，独立扰动材料占约 25%。训练只取几何 FOV 内 1–43 mm 的像素，数值吸收边缘不当作组织衰减。模型与采样特征、训练 ID、输入索引哈希一起保存；使用现有 NumPy/SciPy，不增加依赖，也不占 GPU。

后续物理反演可加入弱的平均负对数密度项，但不采用先验条件均值直接生成三幅结果。先验项强度与完整波形误差分别记录，保持均匀初值参与比较。最终必须实际改善材料图，并由原求解器复算波形。

最强反证是同一声速、密度而衰减不同的已有开发配对：若方法只输出训练中常见的衰减，即便基础病例图好看，也不能声称完成三参数联合重建。当前仅准备统计模型，不把先验拟合或训练集似然作为重建成功。

先验候选增加显式多尺度搜索方向：全局常量、8×10、32×36、当前阶段细网格四层相加后映射到材料参数。最细场仍完全自由，粗层只改变搜索的条件数。使用可逆双曲正切映射保持与纯物理组相同的声速、声阻抗和衰减范围。恢复时先将原参数逆映射，再逐层分解、保留精确细层残差；同一个恢复点必须给出相同物理材料。

该比较同时改变先验和预条件，不能单独归因于其中一项。它针对的是当前实际观察到的背景方向几乎不更新，优先判断这种联合修改能否使三幅图和完整观测同时改善。两个物理进程组同时运行时，分段波场长度不变，预期每卡总分配约 8.5–9 GiB，须以 nvidia-smi 的实际总占用确认小于 16 GiB。
