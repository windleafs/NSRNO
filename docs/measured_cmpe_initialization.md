# 实测共同中点相位用于声速初始化

当前问题仍是原生声速、密度与组织衰减三图恢复。耦合路线首步 RF 降低 5.92%，但 c/rho/alpha 的变化 RMS 只有 0.747/0.652/0.000340，实际图仍平。新的初始化不被算作三参数成功，也不替代正在运行的耦合实验。

考虑过两条不同的途径：增加编码曲率的源数并匹配几何权重，可改善完整波形更新的局部近似；实测相位的反射层析，则不需要当前预测先具有正确的反射结构。前者仍依赖当前波形相位所在的局部区域，后者有机会先补充传播路径上的声速对比。当前先在 CPU 实现后者，不增加 GPU 占用或任何正演数据生成。

使用已有 11 个窄孔径 3 MHz 点发射和全部 192 接收。取相邻发射相差 Δx，同时将接收孔径反向平移 Δx，构成共同中点。V5 的 Δx 为 3.6 或 3.8 mm，分别精确等于 18 或 19 个接收间距。比较局部复解析 RF 的相关相位，不比较相邻接收的任意相位，也不采用全局 CF 极值。固定初始观测的相干权重，防止优化通过降低自身相干性而减少代价。

路径时间采用已保存 RF 初值的慢度积分加线性的空间慢度修正，已知 1 mm 凝胶时间单独计算；CPU 稀疏算子作用于 1 mm 修正节点。观测插值对时间的梯度用自动微分，乘以同一稀疏路径算子的转置得到慢度梯度。最后把修正叠加到 50 μm 原生初值，保留原有细结构。Z 与 alpha 保持 RF 初值，rho=Z/c 随 c 代数变化；这不是密度识别。联合细化时全部原生三个场仍自由。

机制来自 [Simson 等的共同中点相位研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC12971074/)：适当的孔径平移可减少散斑自身造成的相位随机性。本文的窄而稀疏发射、非均匀介质、多次散射及单极/偶极混合不满足其全部近似，所以该目标下降本身不构成声速正确的证据。另一选择 [CUTE 的改进模型](https://doi.org/10.1016/j.ultras.2020.106168) 要求共同中角及成像位置偏移校正，不能将它简化为任意两个角度的相位差。

预设决策：一次有限 32 次迭代的实际初始化后，独立评价保存声速图。若相位目标下降但空间结构仍错，则不把它注入所有模型，不增加一次无意义原求解器复算；若材料图有实质改善，再用完整 RF 判断其是否适合作为联合反演起点。最强反证是相位趋近零而声速对比和组织位置仍不正确。最终三参数结论仍需原求解器复算、固定 c/rho 的独立 alpha 配对及另一开发材料。

在读取本次材料评价之前，将是否值得原求解器复算的必要条件具体设为：相对固定 RF 声速初值，RMSE 至少降低 10%，同时空间相关性超过 0.5，并能在相同色标上看到相应组织位置。这是本次资源分配标准，不是一般可辨识性判据；即使达到也只代表初始化值得进入完整 RF 选择。优化过程中不读取这些指标或真值，候选仍由自身完整相位目标选择。
