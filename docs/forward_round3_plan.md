# NSRNO 细尺度散射与非局部接收聚合

用户已批准继续处理细尺度散射与非局部接收聚合；沿用已批准的独立神经正演路线，不接 Geo-Flow。

## 方案比较与选择

1. 细尺度分支加全频率傅里叶聚合：在 50 μm 原生网格分离平滑背景与细节，细节用空间重排保留原生样值；通过不截断空间频率的可学习算子，使每个接收查询能依赖整个介质。核和散射映射从 RF 监督学习，不加入固定 Born 振幅或物理求解器。优先实现此路线。
2. 只有细尺度分支与局部聚合：相同的细节输入、角度条件、载频输出和冻结基线，以局部深度卷积替换傅里叶聚合，区分细节保留与非局部混合的效果。两者部分滤波参数数目不同，报告实际参数量，不将比较解释为严格容量匹配。
3. 显式到达时间曲线上的稀疏聚合：空间位置与接收贡献更直接，但在异质声速下依赖额外的时延近似，粗采样也容易漏掉随机散射纹理。本轮不采用。

## 实现

- 冻结第二轮 analytic/best.pt 原分支，保留其早期响应；新分支输出增量，初始化为零。
- 分离原生 log c、log rho 的平滑项与高通细节；细节采用固定幅值归一化，并以 4×4 空间重排进入独立特征分支，避免先做均值下采样。
- 使用角度条件和已有累计慢度信息；在介质网格上做两层非局部聚合，在阵元—时间网格上做一层接收聚合。全频率算子采用低秩通道映射与两个方向的完整复数频率乘子，不删去高频模式。局部对照使用 5×5 深度卷积。
- 在接收查询前用 pixel_shuffle 恢复原生 50 μm 网格，按原生物理坐标插值；不直接从打包后的粗网格读取细尺度波形。较早的粗查询试运行单独归档，不纳入正式比较。
- 输出继续采用包含载频的复解析波形，按训练分窗尺度恢复幅值后，精确转回复基带并与冻结模型相加。
- 保持旧检查点可读，新增模型类型由 checkpoint spec 标识。

## 训练与判读

- 数据不变：训练 510 条、病例留出验证 270 条。每轮每条记录取两个轮换角度，batch=4，AdamW，最多 120 轮。
- 目标函数沿用逐记录分窗损失。检查点选择改为开发验证的 8–18 与 18–36 μs 两窗平均相对 RF RMS，预先声明此选择是针对本轮研究问题。
- 每五轮评估固定 64 条基础训练记录及开发验证病例的三个固定角度。至少 60 轮后，若固定训练子集的两窗平均相对 RMS 连续 30 轮未下降 0.0001，提前结束。
- 完成后在完整基础训练集和留出病例的全部 11 角上报告各窗误差，并与冻结的第二轮模型和平均波形比较。主要判断中晚期回波，单独报告早期变化。
- 若两者均不能拟合训练后续回波，不将失败解释为有限角度导致正演不可学习；需要继续区分表示与优化问题。若只有训练改善，则说明泛化仍未解决。只实施影响这些判断的检查。

## 第三组有针对性的坐标改动

局部和非局部原生读取版本在 40 轮附近均未改善 8–36 μs 的训练误差。保留两组既定停止条件，并增加累计慢度查询作为竞争机制：由输入 c 在每列的梯形积分构造单程时间坐标，以 z=0 为参考；对每个接收查询反求深度，再读取原生网格特征。其余分支、冻结基线、目标、非局部聚合及训练预算均不变。

这个坐标近似不求解完整传播，也不包括折射和多路径。它只把输入材料导致的轴向时间变化显式用于查询，检验此前由固定参考声速确定读取位置的限制。深度反求用固定邻域内的线性插值，保留对声速的分段可微依赖。先检查均匀声速的解析极限和实际批次梯度，再训练。若仍不能拟合目标窗，不把结果解释为所有物理传播信息都已被利用。
