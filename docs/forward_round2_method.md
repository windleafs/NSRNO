# 第二轮输出尺度参数化

模型仍是独立的 694786 参数神经正演网络。输入、复基带表示、网络层、平均波形、损失定义、病例划分、训练记录和角度轮换均沿用第一轮逐记录归一化版本。

令 T 为训练基础记录的逐角平均波形，s_w 为训练基础记录在时间窗 w 内的复基带均方根尺度。第一轮输出为 T + s_global rθ；第二轮输出为 T + s_w rθ。rθ 是网络的无量纲输出，RF/IQ 预测值仍保留原物理幅值。640 个复基带时刻依照原有 0、8、18、36、61 μs 窗边界选择尺度。尺度始终由训练数据确定，预测时无需目标 RF。

保留逐记录损失：

L = mean_w mean_(sample,angle) [mean_(receiver,time in w) |prediction-target|² / max(E_target,w, s_w²)]。

窗口输出参数化使无量纲残差的误差系数变成 s_w² / max(E_target,w, s_w²)，其值不超过 1。全局输出参数化则是 s_global² / max(E_target,w, s_w²)，其最晚时间窗的上限约为 398.45。这个结论只涉及数值缩放，不保证优化一定成功，也不保证网络足以表达正演算子。

两组均从相同随机种子初始化，最多 200 轮，AdamW 初始学习率 0.0003，余弦下降至 0.00002，batch=4，每记录每轮两个轮换角度。至少 80 轮后，若固定 64 条基础训练记录在三个固定角度下的逐记录平衡损失，连续 40 轮没有下降至少 0.0001，提前停止。验证检查点选择沿用四窗平均相对 RF RMS。训练停止和验证选择是不同标准。

原全局尺度检查点仍使用标量 rf_scale；窗口尺度检查点通过 spec.output_window_scales 构造长度为 640 的 rf_scale。两者可由同一个 load_forward_model 读取。

## 停滞后的解析波形表示

两个尺度版本都在第 80 轮触发预先规定的基础训练损失停滞条件。窗口尺度帮助了均匀声速 calibhom 的 0–8 μs 响应，但未改善基础乳腺记录或较晚时间窗。

因此增加一组有针对性的训练，保持窗口尺度、网络层、参数数量和训练策略不变，仅改变最后一层输出的复数坐标。令 q[n] 是已有基带表示，k0=360，N=640，则包含载频的复解析波形采样为 a[n]=q[n] exp(i 2π k0 n/N)。新模型预测 a 的残差，再乘 exp(-i 2π k0 n/N) 得到 q 的残差。这个确定的逐时刻复旋转是可逆且保范数的，RF 目标、时间窗和损失权重不变，没有使用传播求解器。

动机：连续解析信号 a(t) 的时间延迟对应 a(t-τ)，而基带 q(t) 还需乘 exp(-i ω0 τ)。以空间局部卷积和名义时间坐标为主的解码器，可能更容易从散射纹理预测包含载频的波形。该表示变换是否有帮助由实际训练决定；它不保证能解决非局部传播，也不证明原基带表示不可学习。

主要结果在最后检查点和按验证选择的检查点分别计算。完整基础训练集与验证集均评估全部 11 角。若总体训练损失与基础记录表现不一致，再按已有补充配方汇总最后检查点的误差，定位收益来源。最后一个独立病例不参与本轮。
