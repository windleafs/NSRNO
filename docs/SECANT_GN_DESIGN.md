# 保留非局部曲率的边界约束 Gauss–Newton

当前目标不变：原生网格、全部采集、独立声速/密度/组织衰减，单卡16GiB。
本设计不把预测RF下降当作材料图成功，也不改变观测数据。

## 当前新证据与认识边界

实际完整原生Gauss–Newton前三个内部片段的最优线段系数为
0.01284495、0.01217297、0.00915140；累计二次模型下降0.02021965。
三个必要HVP的曲率与同次RF切线能量均一致到约1e-8。

当前方向生成是先投影预条件梯度，再沿该可行线段作最优一维步长。
每步 u_new=(1-alpha)u+alpha*v，其中v位于同一物理信赖盒。零初值下
前三步的最大坐标移动不超过盒半径乘以1-product(1-alpha)。这个因子
约0.034，因此当前前三片段无法提供大幅材料变化。这是对内部求解
进度的界，不是患者材料不可恢复的证据。尚未取得最终方向、物理回溯
和材料图，不能断言整个当前Gauss–Newton路线失败。

## 竞争方案

一是继续增加投影CG的HVP次数。机制直接，但每次约5.7分钟，且投影
会改变共轭方向。二是保存已有HVP方向和像，在CPU上构造保留非局部
信息的低秩正定BFGS模型，再求边界约束二次步；选择此方案作为后续
可比较的求解器改进。三是源逐个更新的非线性Kaczmarz，可能改变反射
结构与传播参数形成的先后顺序，但也改变非线性优化轨迹；先不同时
更改这项因素。三者并非三个学习率设置。

## 具体算法

对当前固定材料，真正的二次问题为 g^Tu+.5u^THu，H=J^TWJ+H_TV+D。
保留准确的r=g+Hu。近似B只用于提出步长，不替代真实曲率。

在当前u处CPU求解 min_d r^Td+.5d^TBd，约束 low-u<=d<=high-u。
CPU使用对角缩放L-BFGS-B，不对求出的材料作事后投影。然后执行一次
必需的原生HVP Hd，取真实二次模型的可行下降系数alpha，并更新u和r。
这和逐像素裁剪预条件梯度不同，非局部低秩项在边界求解中保留。

初始B0为校准过的局部物理预条件器、已知TV曲率和正阻尼。每得到新
方向d和准确像y=Hd，就作正定BFGS更新：

 B_new = B - (Bd)(Bd)^T/(d^TBd) + yy^T/(d^Ty).

保存v=Bd和y即可用低秩形式作用于任意向量。所有更新要求两个分母
为正；每次CPU候选与每次真实二次模型步骤都记录下降和边界可行性。
CPU求解达到预算时明确标为近似解，不宣称精确QP收敛。

首个HVP校准初始度量并固定阻尼；之后内层H不改变。保存每个HVP的
方向和数据曲率像，避免中断或后续模型分析时重复患者传播。低秩数组
存CPU，GPU仍仅保留一个发射和一个重算段。优化不读取材料真值。

## 实施与决定

不修改正在运行的源文件。先在第一个完整材料和RF结果处由独立观察
进程暂留协调进程，GPU任务均已完成，CPU画图子进程继续结束。读取
真实材料图后，再决定继续原求解器还是正常关闭其工作进程并启动
新模块。保持原有全部结果、来源SHA及操作原因。这个作业检查点不
改变用户长期研究目标的active状态。

若新二次求解的真实最优性残差明显改善、实际RF回溯也接受较大材料
步长，才说明当前障碍至少部分来自内部求解。若二次模型求解改善但
真实物理回溯仍很小，应转向非线性吸引域或源逐个更新。若二者都正常
而三图仍弱，仍未解决独立三参数成像，不能以RF下降收尾。
