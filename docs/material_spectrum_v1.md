# 已有材料快照的空间尺度诊断

原始联合成像问题尚未解决。本次只读取已保存的材料和后处理真值，执行正交二维 DCT-II，去除常数项，按空间波数分区；没有新传播、导数、优化或真值选取检查点。区域为 x=±19.1 mm、z=1–43 mm、原生 0.05 mm 网格。

| 快照 | c 的 1–4 mm 尺度幅度 / 真值 | Z 的对应幅度 / 真值 | alpha 的对应幅度 / 真值 |
|---|---:|---:|---:|
| 物理坐标，3 MHz 第 64 次 | 0.04255 | 0.03882 | 0.03944 |
| 走时坐标，3 MHz 第 64 次 | 0.04694 | 0.03816 | 0.03984 |
| 物理坐标，加入高频第 32 次 | 0.05209 | 0.04504 | 0.05634 |

第一对为相同更新次数的比较；最后一行只说明加入高频后的变化，不能与走时阶段直接比较优劣。这里的幅度是对应 DCT 系数平方和的平方根，不是雅可比特征值。

两个 3 MHz 完成候选在 0.2–1 mm 尺度的 c 幅度分别达到真值的 0.611/0.598，但相关性只有 0.00279/0.00057。物理组加入高频后，小于 0.2 mm 尺度的 c 幅度达到真值 14.32 倍，而该尺度在真值本身很弱，不能据此夸大伪影的总能量。它与 1–4 mm 结构幅度缺失共同说明：RF 项下降并未转化为正确材料尺度上的恢复。

这支持研究空间更新预条件、源谱整形及边缘先验，但尚不能区分优化偏向、时间错位、散射率初值与弱信息这几种解释。不能从这组结果宣称观测缺失某些空间频率，更不能宣称三参数一般不可辨识。

当前仍优先完成已启动的相位初始化，暂不同时新增完整谱整形反演。相关原始研究 [Plessix & Li 2013](https://academic.oup.com/gji/article/195/1/301/603125) 讨论了源子波与传播导致的梯度谱失衡；其速度已知的阻抗反演结果并非这里三未知场的证明。
