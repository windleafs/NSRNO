## 机制证据与认识边界

8次完整HVP后，真实二次问题的投影最优性残差为初值83.1797%。其内部
线段系数为0.0056–0.0128，后几次的二次模型增益较小。这是当前内部
求解仍很不充分的实际证据，不是数据不可辨识的证明。

去掉仅用于求方向的阻尼二次项后，物理数据加TV的二次模型预测变化为
-0.0254690293，真实物理RF回溯变化为-0.0254328174，两者之比0.9985782。
因此，对当前这个小材料方向，线性化预测与真实下降吻合。不能把这一点
外推为未来大材料方向也没有非线性障碍。

阻尼二次量0.000524031，数据二次量0.030084536，TV二次量0.000031332。
阻尼占数据二次量约1.74%，在这条方向的总体曲率中并不占主导。所有
分解来自已保存的梯度、方向、统计和回溯；新增患者波传播次数为0。
原16个运行源文件的SHA均保持不变。

## 最强反证与剩余障碍

若新方法明显降低真实二次问题残差、接受充分材料变化，物理RF预测也
可靠，但三张材料图仍不出现正确结构，则当前“内部求解不足”解释不足，
应转向非线性吸引域或反射数据中的参数耦合，不能继续只增加CG次数。
当前还没有获得能区分这些原因的新材料结果。

有用的独立三参数图尚未实现，独立衰减配对及其他病例的实际重建也尚未
完成。下一项最有价值证据是新求解器在相同物理问题上的真实内层残差、
接受材料变化与图像，而不是重复旧导数或可辨识性验证。
