# 与现有原生离散方程等价的一阶辅助波场

目标仍为同一 50 μm 网格上独立的声速、密度、组织衰减图，最终完整 RF 由原始时域求解器评价。这里改变优化变量，不改采集、空间 FOV 或材料标签。均匀 3 MHz 内部波场参考只依赖已知采集，不读取任一乳腺的未知材料。

## 为什么增加内部波场

现有约化反演把内部波场完全写成当前材料的正演解。若目前材料没有正确的反射位置，所有更新都在该波形附近的局部几何中进行。拟采用交替反演：先允许内部压强、速度波场偏离当前材料的严格传播解，拟合实测数据；再由其方程残差更新材料，并用增广拉格朗日变量逐步消除方程与数据残差。它是一条与单纯改进约化 Hessian 不同的路线，不保证克服有限角度造成的信息不足。

相关依据：[Song 等三参数 CSI](https://pubmed.ncbi.nlm.nih.gov/32142427/)使用多频、多发射、多接收及辅助对比源减轻非线性，其低频胸腔条件不同于本项目；[van Dongen 与 Wright 的矢量 CSI](https://pubmed.ncbi.nlm.nih.gov/17407891/)保留压强和速度场；[多参数 WRI](https://academic.oup.com/gji/article/219/2/1316/5545595)也说明场扩展本身不会消除参数辐射模式及串扰，仍需边界和空间正则化。以上不是本项目三参数可行性的证明。

## 从已有压力算子得到等价三分量系统

记 D=exp(i omega dt)，S0=(D−1)/(dt c0)，v_tilde=rho0*c0*v。现有 `ConditionedFrequencySystem` 已经实现同一个八阶交错差分、原始压力形成顺序、分裂 PML 及离散双弛豫。其压力方程写为

    A_p p = b(omega) p + C * sum_axis part_axis(a_half*sv_axis*Dplus_axis p),
    C=(D−1)/(D*k0²),   k0=2*sin(omega*dt/2)/(dt*c0).

这里 `part_axis` 恰为现有原生算子的 PML 散度组合，不能换成普通连续散度。定义

    G_axis = Dplus_axis / S0,
    R_axis = 1/(a_half*sv_axis),
    L_axis = dt*c0*part_axis.

三分量方程为

    b(omega)*p + Lx*vx_tilde + Lz*vz_tilde = source,
    Gx*p + Rx*vx_tilde = 0,
    Gz*p + Rz*vz_tilde = 0.

因为 (D−1)²/D = −(dt*c0*k0)²，消去速度后的系数 −dt*c0/S0 正好等于 C，得到原来的压力算子，包含 PML，未使用直线路径近似。FFT 外围填零区的三个场都固定为零，原生材料边缘仍按原求解器先裁 24 格再复制的规则处理。

参考场的速度由参考材料的速度方程构造。未知散射场方程的右端可直接用局部系数差计算：−(B_m−B_ref)U_ref。三个材料的源位置均为已知凝胶，因此源项相同；微分/PML 项也相同，完全抵消。这样不需要对两个巨大的入射场做差分后再相减。有限记录的材料依赖末态项仍与既有频域近似有同样的缺口，必须靠最终独立时域 RF 评价，不能隐瞒。

## 固定波场后的三材料更新

采用三个独立原生量

    r=rho/rho0,
    beta=(rho0/rho)*(c0/c)²,
    t=alpha_total*c/c0.

压力系数 b(omega)=beta*M(omega,t)，M 为已有离散弛豫模量的逆。两个速度系数是 r 在交错位置的算术平均乘以已知 PML 因子。固定波场后，r 的子问题只来自速度方程，是邻接点相加的实线性最小二乘；beta/t 只来自压力方程，可累积每个位置的 2×2 正规方程。beta 和 t 的复数导数已在 `relaxation_inverse` 中写出。它们在完整数据反演中仍通过未知波场耦合，这个分块只针对条件材料子问题。

交错平均的密度子问题有高频棋盘方向，必须由已知凝胶、独立空间正则化和阻尼约束，不能误把其条件好坏当作密度可辨识性证据。由 r、beta 得 c=c0/sqrt(r*beta)，由 t 得 alpha_total=t*c0/c。已知边缘吸收须单独扣除并固定其贡献，组织衰减保持正，三个原生细场继续自由，不规定共边界。

## 内存与观测范围

计划逐频率、逐发射处理全部 11 发射、192 接收与 3 MHz 带内 180 个连续频率点（1.516–4.498 MHz，间距 16.660 kHz）。固定参考约 17 GiB，三分量散射场及相应增广变量约 120 GiB，放在 NVMe 上；可用磁盘已实测约 666 GiB。显存只容纳一个频率、一个发射的场及短递推向量。参考生成每块 32 频率，FP64 累积，分配上限 1.1 GiB，并检查包含 CUDA 上下文后整卡仍低于 16 GiB。

参考捕获以与 RF 相同的 40 MHz 时间点读出，波动方程每 2.5 ns 的更新保持原样。带外源频谱在该抽样 Nyquist 外极弱；这种读出不会被当作新的已验证材料正演。生成时直接比较同一次捕获的接收点频谱与同一次原生 RF，以及已有均匀参考 RF，无额外材料扰动或重复传播检查。

当前仅已实现一阶算子、其解析伴随、块神经预条件器及固定参考的生成。完整交替优化器尚待实现；没有新的三参数成像结果。新的辅助波场若只拟合数据而不能消除方程残差，或其材料不能通过完整原始 RF 复算，就是该路线的最强反证。第二个开发材料、独立 alpha 配对与最终三图仍是完成条件。
# 2026-11-06：完整接收块与多发射场求解

紧致格式还必须包含对应源项权重。对常系数内部，Q=I+h²Δ5/12，Ac=mass*Q+Δ9/k0²近似Q*A。因此压力逆应取T9=Ac^-1*Q，伴随T9*=Q*Ac^-H。原实现省略右端Q，造成高空间频率分量被错误放大。变量系数/PML下仍只作为预条件近似；原八阶方程始终用于正规矩阵、真实残差和接受检查。实际受控场求解中，只补上Q使全部11发射从32次块CG残差约3%变为8次后约0.25%；这不是材料信息增加，而是同一线性子问题更准确地求解。

上述原生三分量方程B与材料参数化均保持不变。为解固定材料的场问题，在变量X=X0+Pz中，正规矩阵是

    N = P* C* C P + lambda P* B* B P.

仅用近似B逆P时，192个接收通道产生的第一项仍可能造成很大的谱跨度。令K=C P、U=K*，用Woodbury恒等式构造正定预条件器

    M = (lambda I+U U*)^-1
      = [I-U(lambda I+U*U)^-1 U*]/lambda.

这里使用全部192接收通道，未做接收或频率截断。M中的lambda沿用原冻结场罚系数；Gram矩阵只加保守浮点误差余量，不修改场目标或缩放乘子。M近似N的前提是P* B* B P接近单位阵，因此接收块修正不能消除压力逆自身的误差。

P是原一阶方程块消元得到的逆。对只含压力接收源的输入，U的三分量可以从一个压力场w重建：

    T w = [w, -Ix* Lx* w, -Iz* Lz* w],
    T* [zp,zx,zz] = zp-Lx(Ix zx)-Lz(Iz zz),
    U = T W,  W = P_pressure* C_pressure*.

因此仅存储192个压力场的实部/虚部即可计算U的乘法、伴随与U*U，而无需为每个接收通道保存三个场。当前FFT尺寸下这部分约1.837GiB。接收Gram是192×192，不是材料雅可比或可辨识性实验。

压力预条件器可用原生50μm网格上的九点紧致稀疏矩阵，再与冻结神经压力逆F组合Pp=F+T9(I−AF)。T9的伴随用共轭转置LU求解，因此Pp*是解析伴随。紧致格式在常系数内部具有四阶精度；变系数与PML仍是预条件近似，实际正演和正规残差始终使用原50μm八阶算子。静态主元模式只影响LU求解策略，不改变正演方程。

对同一频率的11个发射使用块共轭梯度，让其共享Krylov搜索空间；各发射的RF、原始增广右端和残差分别保留。一个频率的资格结果不能当作全部450频率收敛，更不能当作三参数恢复。

从场已完成但材料未更新的检查点继续细化同一问题时，保存量是Y_base=b_shift−B_old X、Ydata_base=d_shift−CX。故应直接恢复原始增广右端b_shift=Y_base+B_old X、d_shift=Ydata_base+CX，不能把Y_base直接当下一次乘子重新加到rhs，否则会额外执行一次未声明的乘子更新。细化后再次保存相同意义的Y_base，随后材料步与原有局部乘子更新保持原顺序。

## 2026-11-06：固定场曲率与波场消元后的材料曲率

以下为直接线性代数推导，尚未作新的材料实验，不是三参数可恢复性的结论。它给出一个需要与信息不足相区分的机制：固定场交替更新可能因条件曲率过大而收敛很慢。

在某个频率和固定乘子下，把观测能量归一化吸收到权重，记

    r = [C X-d-Ydata; sqrt(lambda)*(B_m X-rhs(m)-Yeq)],
    A = [C; sqrt(lambda)*B_m],
    J delta_m = [0; sqrt(lambda)*delta(B_m)*(X+U_ref)].

材料为实变量，场为复变量，材料梯度和二次型按复内积的实部解释。一次联合Gauss–Newton子问题为

    min_{delta_X,delta_m} .5*||r+A delta_X+J delta_m||²
                          + 材料TV的局部二次模型及阻尼。

令M=A* A，Π=I−A M† A*（†为Moore–Penrose逆；在受限场空间可逆时即普通逆）。消去delta_X后，数据部分变成

    .5*||Π(r+J delta_m)||²,
    g_reduced = Re(J* Π r),
    H_reduced = Re(J* Π J) + H_regularization.

场子问题若精确求解，A* r=0，故g_reduced=Re(J* r)，与当前固定场材料梯度相同；实际场只达到数值容差时，不能把这个等式当成严格事实。当前固定场GN使用

    H_conditional = Re(J* J) + H_regularization,
    H_conditional−H_reduced = Re(J* A M† A* J) >= 0.

最后的不等式是二次型意义上的半正定性：允许波场随材料重新调整，会消去一部分条件曲率。因此即使材料梯度非零，固定场更新也可能给出很小的声速/密度步。这一推导只证明存在这样的数值机制；约化曲率很小也可能意味着观测本身对该方向约束很弱，不能反过来据此宣称参数可辨识。

当前第3步仍采用原交替方法，不变更正在运行的代码。待完整场更新、实际材料步和完整原生RF/三图出来后，若场已足够准确而声速/密度仍停滞、衰减主要消耗信赖域，才考虑联合场—材料步。候选是用少量材料方向近似上述Schur补，同时保留全部原生独立三场的局部更新；这些方向是补充搜索方向，不能变成强制平滑声速或共同边界的最终参数化。每次矩阵乘法都重做450频率的内层求解代价过高，具体实现必须先控制这部分成本和单频显存，不能只写出公式就宣称可用。

最直接的反证是：条件曲率与波场消元后的曲率在实际有用方向上接近，或实际耦合更新仍不能改善完整物理RF和三图。前者会削弱“条件曲率导致停滞”的解释，后者说明即使该机制存在也尚不足以解决重建。当前没有新增该方向的有限差分、可辨识性或单场探测实验；优先等待正在进行的完整材料结果。

## 候选：先消去速度，再定义压力波场扩展

这与上节的联合场—材料GN是不同的选择：上节保持现有扩展目标、改进联合更新；本节改变扩展目标的状态和残差度量，但保留当前频域模型的物理解。以下仍只为推导，未实现、未运行。

把当前一阶系统写成B=[K L; G D]，p为压力，v为两个速度分量。D是在活动场空间可逆的速度质量块；令T=L D^-1、S=K−T G。对固定材料、压力和乘子，设两个方程残差为e_p、e_v，则

    e_s = e_p−T e_v

与速度v无关。通过对速度残差配方，得到

    min_v (||e_p||²+||e_v||²)
       = <e_s, (I+T T*)^-1 e_s>.

因此，当前三分量扩展目标在消去速度后，并非普通的压力Schur残差||e_s||²，而是含材料相关度量W_m=(I+T T*)^-1的压力残差。在均匀、可傅里叶对角化的内部，W_m的符号为1/(1+|T_x(k)|²+|T_z(k)|²)，会相对减小大空间波数残差的权重。变系数/PML下仍有上面的算子恒等式，但不能将均匀符号当作整个区域的精确谱。

这提供另一个候选机制：细尺度密度散射主要进入含空间导数的压力系数变化，当前扩展度量可能削弱其中一部分高空间波数信息。该推断尚未由成像实验支持；它不意味着数据中一定有足够的独立密度信息，也不意味着更强调高空间波数必然得到正确图像。

如果另起压力-only WRI，可对同一个物理Schur压力算子S_m定义扩展残差，并保留原生独立r/beta/t三场。密度在固定压力下通过S_m的系数导数直接进入材料步，原有一阶速度质量块的材料充分统计量不能直接沿用。新目标还需要一致的标量乘子定义，不能把当前Y_p或Y_base直接当成新乘子而宣称沿用同一迭代。

压力未知量、压力乘子及对应Krylov场数组的分量数由3变1；现有192接收压力基、LU因子与cuSPARSE工作区不会按同样比例缩小，因此不能在未运行前声称总显存降低三倍。全部11发射、192接收、现有连续频率、原生材料自由度和43mm评价范围都应保留。密度材料步具有空间耦合，需要单独估算其运算与存储成本。

是否采用仍由本轮实际材料结果决定。若压力写法的实际完整反演仍不能改善真实RF和密度/声速/衰减图，这个残差度量机制就不足以解决问题；不能用单频压力拟合或较低显存代替三参数重建证据。
