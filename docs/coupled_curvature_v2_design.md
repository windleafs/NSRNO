# 耦合更新的下一版：准备代码，尚未启动实验

v1 首步完整 RF 数据项降低 5.92%，但实际三场几乎仍为初值；8 次内层 CG 相对预条件残差为 3.704，没有达到 0.15。第一次完整回溯中，沿提议方向的有效二阶曲率约 3.4–3.6，完整步长与半步均使目标增大，最终仅接受 1/8。它不能单独区分编码方差、不同加权度量和非线性残差项，但已经说明当前近似对该方向的大步预测过于激进。

v2 保留同一原生物理求解器、全部独立发射的梯度、完整 RF 选择、独立三个物理场以及原有弱 TV。仅修改局部曲率估计和截断求解的预条件器：

1. 将旧的绝对时间窗内层权重改为目标中所有发射的几何权重的平均。它仍是正定近似；不同发射各自的权重不能精确由单一编码表示，禁止称为完整目标的精确 Hessian。
2. 每个外步和来源固定两个包含全部 11 发射的符号编码，内积为 1，使用两个正规算子的平均。第二码的边际分布仍为 Rademacher；固定翻转五个随机分量减少两码相关。缓存两组独立检查点，避免每个曲率乘积额外重算基态。
3. 当前全部数据梯度在 PCG 的标准化坐标中提供三个正的块缩放，和已有空间预条件器相乘。块常数与空间算子可交换，所以组合仍为对称正定。它只改变有限 8 次 CG 预算的分配，不改变充分收敛时所解的方程。尤其不能从很小的 alpha 更新直接推论衰减不可观测。

这些变更不保证组织成像。最强反证仍是完整 RF 继续下降而三张实际材料图不恢复，或 alpha/密度只补偿声速位置错误。若 v1 已给出可信三图，下一项应首先完成原求解器和独立材料检验；不应为完成方案列表而再跑 v2。

资源：单工作进程分配上限 4.75 GiB、chunk=96；启动必须满足整卡预测占用低于 16 GiB，主机可用内存至少 100 GiB，留出两套 host 检查点。当前旧控制、相位和 v1 均继续运行，内存不满足，因此只生成独立 v2 文件，不启动新的优化或自动等待任务。不终止任何正在运行的优化；旧两控制的提前停止授权问题仍未获答复。

v2 与正在运行的 v1 源文件完全分开，生成程序核对当前 v1 和启动时归档源逐字相同，保存三个新模块。沿用已确认的原生切线，不重复材料可辨识性或有限差分检查。正式运行前只需要语法检查及核对资源；实际运行本身的完整 RF 和三图负责判断研究价值。
