# 三材料耦合曲率更新

目标仍是独立的原生 c、rho、组织 alpha 三图。已完成的原生 L-BFGS 基线没有恢复三图；正在运行的两种 Adam 坐标组也尚未恢复组织对比。新的相位初始化在检验时间错位。这里准备的是另一种机制：联合求解材料间的局部耦合与空间尺度，而非继续修改三个独立 Adam 的步长。

## 候选与区别

1. 当前相位初始化：改变非凸数据目标的吸引范围，仍使用一阶更新。若相位项下降但真实 c 对比不恢复，说明只有时间错位解释不足。
2. 本候选：用原生离散传播的切线 Jv 和既有伴随 J^T，求一个带阻尼、弱 TV 的耦合正定更新方向。它处理局部病态曲率，不能自行跨越任意波形周期。若精确目标下降而三个场的组织尺度仍缺失，低阶曲率不是唯一障碍。
3. 边缘稀疏 / 源谱整形：可能补偿反射更新的空间谱失衡，但会引入额外先验或改动数据度量。本次先不同时启动，避免无法判断主要障碍。

## 精确与近似的边界

Jv 对原生 8 阶交错、分裂 PML、两松弛机制、密度半节点和材料外缘复制全部求导。新增实现用独立的 CUDA 动态库，包含既有 native_time.cu，不修改运行中的求解器文件。切线仅同时推进基态和扰动，不存时间历史；J^T 复用现有检查点伴随。

优化目标和候选接受必须使用完整 11 次发射、192 接收的实际几何 RF 目标，不能只用编码误差选择最终材料。矩阵自由曲率允许使用包含全部 11 发射的固定 Rademacher 源编码，在一个内层求解中固定编码；其时间窗权重与几何目标不同。因此它是正定近似曲率度量，不能称为几何目标的精确 Gauss–Newton Hessian。真实全数据梯度和回溯用于控制其偏差。所有保留频率仍在传播响应内。

物理坐标继续用 c、Z=c*rho、组织 alpha，三者全自由；rho=Z/c。标准化后 δc=80δq_c，δrho=rho(0.1δq_Z−δc/c)，δα=0.7 alpha_tissue δq_alpha。参数曲率只用这些一阶链式映射，不能把材料映射的二阶项混入 Gauss–Newton 项。

CPU 内层 PCG 可用 Neumann DCT 的 Sobolev 正定预条件，保留所有原生模态，不对最终 c 施加平滑子空间约束。已有弱 TV 只作用于各自坐标，不规定共边界或组织标签。对近似曲率不可接受的方向，完整 RF 回溯会拒绝并增加阻尼。

## 当前实施顺序

先实现新增切线，并只做一次必要的实现一致性核对：在既有 RF 初值、一个全部 11 角编码上，用实测残差检验 <Jv,r>=<v,J^Tr>。三个通道的方向按伴随内积贡献平衡，避免声速主导时掩盖密度或衰减实现错误。这里检验新增算子代码，不再重复旧的材料导数可辨识性实验。还核对同一次切线传播中的基态与既有传播一致。

核对进程上限 4.9 GiB，启动前预留 CUDA 上下文后整卡仍需小于 16 GiB。完整耦合反演暂不启动，等待当前比较和资源决定；不因日志安静或一次 SSH 超时重启现有进程。

科学完成条件仍是实际三图及组织对比恢复、原 UltraWave 复算、独立 alpha 配对与另一开发材料，不是这个切线一致性核对通过。

## 实际实现记录

新增切线与旧伴随的平衡三材料方向内积相对差 2.6672e-8，峰值 4.26986 GiB。基态散射 RF 差 5.7873e-6 超过最初 2e-6 的检查阈值，原始未通过记录保持不变。随后只读比较 CUDA 算术核的机器码，基态各核完全一致；旧库自身仅改变是否存检查点，散射 RF 也相差 5.2079e-6。按预先记录的重复性复核规则，新增基态差与当前浮点重复性量级相符；源注入原子加法的执行顺序是候选机制，未将其猜测写成已经直接观察到的事实。没有改变 CUDA 传播公式去迁就检查。

CPU 坐标转换逐元素保留既有 c/rho/alpha 初值，三个场最大差均为 0。PCG 在已知正定三参数耦合系统上 3 次收敛，相对已知解误差 1.39e-16。以上只支持实现进入实际优化，不支持三图恢复。

完整程序 `reconstruct_coupled.py` 已实现：全 11 角实际梯度和候选回溯、固定编码的矩阵自由曲率、CPU PCG、原生自由场、盒约束、独立弱 TV。单次编码包含全部 11 发射，完整目标不做源编码。暂定 8 个外迭代，每次最多 8 次 PCG，三卡各一个工作进程、上限 5.75 GiB。

耦合组直接使用已固定、由完整 RF 选出的物理组 3 MHz 第 64 次初值；这也是原物理控制高频阶段的起点。相位组独立继续。这样分别检验目标吸引范围与局部曲率，不要求未成功的相位初始化成为共同前提。
