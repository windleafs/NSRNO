# 扩展波场残差与材料正演误差

2026-11-06，使用已经完成的第 3、4 轮平面波场日志；没有新传播、材料
导数实验或真值数组读取。数字保存在 `existing_log_diagnosis.json`。

第 4 轮完整 180 个平面波频率、1980 个发射任务的未增广 RF 半代价为
5.3068333e-6，方程半代价为 5.6628345e-4；第 3 轮对应为 2.6024242e-4
和 1.8170409。二者分别下降约 49 倍和 3209 倍。这里的 RF 来自自由的
扩展波场，不能替代材料经原生求解器传播后的 RF。

设 e=b-BX，d_e=d-CX，且 B 在规定边界条件下可逆。材料物理解为
X_phys=B^-1 b，则 d-CX_phys=d_e-CB^-1 e。因此真正有约束力的是经过
CB^-1 放大的方程残差，而不只是原始加权方程残差。令 D=||d_e||²/2、
P=lambda||e||²/2、Gamma=||CB^-1||²，则物理 RF 半代价不超过
(sqrt(D)+sqrt(Gamma/lambda)*sqrt(P))²。所有组能量归一化同时乘入即可。

当前日志里的 Gram 对应近似逆，所以其最大特征值不能直接当成上述
精确 Gamma 的认证上界，但能揭示权重相对于当前求解坐标的尺度。
第 4 轮平面波 lambda/Gamma 的中位数为 0.000725136，而初始选权重的
比例为 0.01，相差 13.79 倍。全频范围为 0.000552164–0.001911083。
第 3 轮完整点发射组的范围为 0.000536215–0.001920495。

原因有直接代码依据：最初用仅含神经近似逆的 power iteration 选取
lambda，之后保持它不变；后来采用原生网格压力校正的近似逆。保留
lambda 没有改变既定目标函数，但它相对于新近似逆的接收放大尺度
比原定比例更弱。有限外迭代预算下，这可能使波场仍能通过较廉价的
方程残差拟合 RF，而材料更新缓慢。它不是数据不可辨识性的证明，
也没有证明单纯增加权重就能恢复三参数。

已准备的新压力路线会从当前必需的接收 Gram 直接定标 lambda，避免
沿用上述旧尺度。新路线同时改变压力扩展场的残差度量、密度材料
雅可比及初始乘子，并从 RF 选定的材料重启。未来若成功，不能把
全部收益归因于单独消去粒子速度；若失败，则应继续区分条件材料
曲率、方程权重和真正观测信息不足，不能机械重复相同外迭代。
