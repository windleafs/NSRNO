## 需要区分的两个障碍

改变一阶扩展场为压力扩展场，会改变残差度量和固定场的材料雅可比。
它仍然使用条件材料曲率，不能由推导保证克服交替更新的刚性。
接收 Gram 的实际日志还显示原权重相对于当前近似逆偏弱；增加权重
可减小扩展场自由度，却也会增大条件材料曲率。两者不可混为一谈。

## 精确联合消元

以下针对一个频率，把全部发射作为多个右端。S 是压力方程，C 是
全部接收通道算子，lambda>0。记当前增广残差为

    r_d = C X - D,   e = S X - R,
    J q = delta S(q) (P_ref + X),
    H_xx = C* C + lambda S* S,
    g_x = C* r_d + lambda S* e.

J 已包括散射右端随材料变化的贡献，不能只用 X 代替总压力。联合
Gauss–Newton 消去场增量后，材料曲率和梯度为

    H_red = lambda J* J - lambda^2 J* S H_xx^-1 S* J,
    g_red = lambda J* e - lambda J* S H_xx^-1 g_x.

只有 g_x 足够小时，条件材料梯度才等于约化梯度。条件曲率与约化
曲率之差为半正定项；所以条件更新可能在可与场变化相互补偿的方向
上过于保守。这不证明该方向可辨识，也不证明约化 GN 一定恢复材料。
材料增量 q 是实数；材料正规矩阵和梯度均取复内积的实部，在材料
回传处，星号应按实伴随理解。

若 S 可逆，定义 P=S^-1、K=C P、Gamma=K K*。则

    H_red = lambda J* K* (lambda I + Gamma)^-1 K J.

这个公式只涉及 192×192 的接收矩阵及波传播算子，而不需要组装
百万维稠密材料矩阵。它与条件曲率 lambda J*J 的本质差异是：后者
也惩罚无法在接收端观测到的方程源方向。

## 可实现的局部耦合近似

直接在全频率外层 CG 中反复应用 H_red，会反复建立原生压力因子，
代价很高。可以先计算 H_red 的每节点 3×3 主块，用它和独立参数
的 TV 曲率构成材料方向的近似正规算子。这个近似忽略不同材料节点
之间的长程曲率，因此必须明确它不是完整的约化 Gauss–Newton。
若用现有压力近似逆代替精确 S^-1，得到的主块也只是近似值，不能
把已完成的单次近似逆检查扩大成所有频率上精确消元的证明。

令 Q=sqrt(lambda)*(lambda I+Gamma)^(-1/2)，W_j=P* C* e_j。
接收 Born 导数为 (KJq)_j=<W_j,Jq>。若 W 按接收阵元逐行储存，白化
后的基应为 conj(Q) W，保证 <W_tilde_i,Jq>=(Q KJq)_i。这里的复共轭
不能省略。

固定总压力下，beta 和 t 的导数分别是 .1 M P_total 和
.1 beta M' P_total；密度通过 L*W 与压力通量的乘积进入。每个密度
节点只需聚合两方向相邻的四个面通量。系数 crop-and-replicate 的
重复 ghost 节点仍需先相干求和，再计算灵敏度平方和，不能先取平方。

逐接收小批次（例如 1–4 个）构造所有 11 发射的三参数 Born 列，
累积其六个实 3×3 Gram 图。原生网格上六图约 49.3 MiB（float64）；
完整接收压力基约 1.8 GiB。白化接收基可按空间块原位变换，以免同时
保留两份；具体 GPU 峰值必须在实际阶段确认，不能由数组估算宣称
已经满足 16 GiB。全频率、全部接收阵元和材料分辨率均不删减。

## 候选必须同时更新波场

用约化曲率求材料方向，却仍然以固定旧波场的代价接受它，会重新
引入条件曲率的障碍。设首个材料方向是 q1，线性材料源为 v1=J q1。
消元产生的首个场方向必须同时包括原场梯度的修正：

    z1 = e + v1,
    delta X1 = -P z1 + P K* (lambda I+Gamma)^-1 (K z1-r_d).

当原场达到条件最优时，它退化为 -P v1 + P K* M^-1 K v1。
这里必须用 J q1，不能把有限非线性系数差冒充 Gauss–Newton 的线性
方向。系数差仍在实际候选代价中精确计算。

投影材料梯度可用白化残差 Q(K e-r_d) 与白化 Born 列内积计算。对于
精确 P，这正好包含未收敛场梯度的消元修正，不需要假定 g_x=0。

场阶段另存很小的 t=K e-r_d。首个联合候选本来就会计算
K(e+Jq)-r_d，所以可直接减去 t 得到 KJq。由此记录同一方向的
lambda||Jq||²、lambda<KJq,M^-1 KJq>，以及条件/投影材料一阶斜率，
无需额外传播。它能在同一波场、乘子和材料状态上比较两种曲率。
P 为近似逆时仍需保留对应的证据范围，不能据比值单独宣称机制已证实。

Gamma 在此前必需的接收矩阵计算中保存。首个联合候选只需重建
压力因子和少数 11 右端求解，不必再次建立 192 个接收基。然后缓存
首个完整压力 X_old+delta X1；回溯取 X_trial=X_old+alpha delta X1，
材料则取相应投影后的 alpha 方向。这是一条固定的联合方向，后续
回溯只需代入物理算子计算实际目标，无需重建传播因子。

接受准则必须代入 X_trial、S_new 和新右端
R_new=R_old-(S_new-S_old)P_ref，计算完整 450 任务上的实际增广 RF、
方程半代价和 TV 变化。它不增加新的患者观测，也不是材料真值目标。
原生时域 RF 和材料图仍在完整更新后独立评价。

首个候选压力可写入单独约 40 GiB 银行，并在回溯期间保持不可变。
若接受 alpha<1，应先把完整缩放后的 X_trial 写入第二个约 40 GiB
银行，确认所有频率写完后，再复制到主 X；否则中断后重复缩放会
改变同一方向。接受 alpha=1 时可直接使用首个完整银行。磁盘预算
必须包含最坏 80 GiB 临时场和至少 16 GiB 余量，不删除原实验数据
来掩盖不足。最终复制可以幂等恢复。接受后的乘子可直接重算为

    Y_new = R_old - (S_new-S_old)P_ref - S_new X_trial,
    Ydata_new = D - C X_trial.

它们只依赖不可变 R_old、D 和保存的 X_trial，不依赖半写入的 Y 或
已经覆盖的 X_old。这保持了当前压力银行恢复设计的语义。

## 最强反证与研究决策

若实际材料方向已明显增大、联合目标下降，但原生 RF 与 c/rho 图
仍没有恢复，则条件曲率不足以解释失败，应优先区分多周相位局部
极值和观测信息不足。若实际联合目标在小步长下仍不下降，应首先
检查近似压力逆、未消掉的 g_x 及局部曲率近似；不能直接归咎于数据。
没有患者结果前，本文件不构成三参数可重建的证据。
