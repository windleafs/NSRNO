# 波场未收敛与物理模型失配的区分

2026-11-05；项目 `/home_nvme/zhuangyang/nsrno`。本轮没有重新训练或扩大网络，没有改变双参数成像目标。

## 核心结论

当前误差中至少有两项已经被直接区分：**固定 8 次波场更新没有解准现有方程；共享衰减系数与组织掩膜不能代替 V5 的局部弛豫图。** 这两项都属于正演实现的问题，不能据此断言声速、密度数据缺乏可辨识性，也不支持把最终目标改成平滑声速。

本轮完成的是误差机制诊断和收敛参考实现。原始任务仍是从物理参数准确预测完整 RF 并服务于双参数反演；完整宽带 RF、晚时刻回波、反演梯度准确性及最终留出病例尚未完成验证。

## 1. 保持方程不变，独立求解

固定第五轮弛豫模型的全部参数、c/rho 输入、局部衰减近似、源响应和接收定义。先得到原来的 8 次更新结果，再使用重启 GMRES 求解同一个线性频域方程。GMRES 在残差生成的 Krylov 子空间中组合多个修正方向；停止标准仅使用方程相对残差 `1e-4`，不使用目标 RF。

第二开发病例 `train_200`、5.997501 MHz、0 度的结果：

| 求解方式 | 方程相对残差 | 相对通道谱 RMS |
|---|---:|---:|
| 原来的 8 次神经更新 | 0.333565 | 0.734140 |
| GMRES，保留学习到的强边界缩放，2560 步 | 0.122077 | 0.266411 |
| GMRES，仅使用频域预条件器，672 步 | **8.4541e-5** | **0.245587** |

第一种 GMRES 没有达到停止标准。学习到的边界缩放会把吸收层方向压得很小，妨碍独立求解器消除那里的残差。将这一缩放从预条件器中移除后可以收敛；**方程本身没有改变**。

为排除只在单一观测有效，在 `train_000`（Neg_07_Left）和 `train_200`（Neg_35_Left）上，使用约 4.498、5.998、6.997 MHz 与 -8、0、8 度，共 18 个观测：

| 一个样本/病例，九个频率角度组合 | 原 8 次更新 | 第四轮 RF 模型 | 同一方程充分求解 |
|---|---:|---:|---:|
| Neg_07_Left | 0.601767 | 0.583675 | **0.372788** |
| Neg_35_Left | 0.756822 | 0.656628 | **0.306501** |
| 合并能量加权 | 0.688974 | 0.623719 | **0.338985** |

18 个观测全部达到 `1e-4`，全部优于原 8 次更新及第四轮模型。GMRES 使用 480–864 次更新；本次 A6000 实测约 1.96–3.48 秒/介质/单频/单角，包括初始化和比较所需计算。它是数值参考，不是已经实现的快速神经代理。上述结果来自两个样本，不是整个病例全部切片，更不是完整 RF 或 18 个患者。

## 2. 把生成器内部场直接代入方程

在独立进程中给原 UltraWave 更新添加 Fourier 累积器，保留原始压力更新，提取 `train_200` 和均匀参考在 5.997501 MHz、0 度的完整内部压力场、实际 c/rho/eta 系数、末时刻状态和通道信号。修改没有写入上游生成器，只在本次诊断进程中构造记录算子。

内部场的接收位置值与原生接收数据直接 Fourier 积分一致，均匀参考相对误差为 `4.46e-6`；重放后带通 RF 与已有 V5 缓存的相对差为 `1.99e-5`。这些检查用于确认记录内部场没有改变所比较的数据。

有限时间 Fourier 变换不能直接当成无限长稳态解。本轮显式推导并使用末时刻压力、速度、密度和两个记忆变量产生的端点项。内域取 z=1–40 mm、|x|<20 mm，避开源和吸收边界：

| 代入同一真实内部场 | 相对散射方程缺陷，扣除端点后 |
|---|---:|
| 网络现有局部系数 | 0.0172652 |
| 生成器真实局部系数 | **0.00013117** |

端点项本身约为右端的 `0.000152`，不足以解释现有系数的 0.0173 缺陷。实际均匀入射场与当前入射模型在一个复数幅度校准后的形状差为 **0.003455**；原生通道谱与带通/重采样目标谱的差为 **0.001500**，复数幅度校准后为 **0.000470**。这些差异存在，但在该观测上不足以解释约 0.3 的剩余误差。

## 3. 局部弛豫的因果对照

构造独立频域参考，使用生成器的 c/rho、双弛豫参数、分裂场边界及有限时间端点项。源来自均匀参考内部场，与材料目标无关；没有用材料目标拟合源幅度。这是带有真实系数和末状态的 **oracle 诊断**，不能作为只输入 c/rho 的部署性能。

实际生成的 C 内核还有一个必须保留的顺序：先用暂时未施加边界阻尼的速度/密度计算压力，再覆盖边界状态，最后注入源。仅照连续 PML 形式写频域算子会遗漏这一点。修正执行顺序后，真实内部场的全域方程缺陷从 0.00983 降到 **0.00013916**；内核已保存在 `physical_operator.c`。

最终双精度结果：

| 设置 | 方程相对残差 | 对原生通道谱的相对 RMS |
|---|---:|---:|
| 真实局部弛豫系数 | 6.06e-8 | **9.23e-5，即 0.00923%** |
| 同一 c/rho，换成当前共享系数与组织掩膜 | 5.67e-8 | **0.299865，即 29.99%** |
| 上一行再补上已知横向吸收区 | 6.06e-8 | **0.299707，即 29.97%** |

三个控制使用相同 c/rho；末状态项保持不变。真实系数参考与原带通目标谱的差为 0.001446，主要量级与已经测得的后处理差一致。前期单精度/简化边界试算得到过 0.018% 和 0.173% 的原生通道谱误差，最终以上表的双精度、正确更新顺序结果为准。

已知横向吸收区由生成配方直接给出，补上它几乎没有改变这项误差。因此该观测的问题主要仍在组织局部弛豫近似，不能只通过修补几何边界吸收解决。当前模型共享系数为 0.58838；原配方为脂肪 0.45、腺体 0.65、皮肤 0.90、血管 0.20、耦合介质 0.002，并通过组织体积分数混合。弛豫同时改变吸收与频散，故错误系数会影响振幅和相位。

## 4. 数学与实现要点

记 `D=exp(i omega dt)`、`q=D^-1`、`A²=[1+(eta1+eta2)/2]²`，则

`H = sum eta_j / { A² [1+tau_j(D-1)/dt] }`

`C(omega) = A²(1-H) / [1-(1-q)H]`。

内域压力方程使用 `omega_d=2 sin(omega dt/2)/dt` 和复数压缩率 `b/C`，其中 `a=rho0/rho`、`b=a(c0/c)²`。有限时间窗的旧状态 Fourier 变换满足 `F[x_n]=q F[x_(n+1)]-x_N q^N dt/T`，端点项据此消元。

边界处需要区分存储后的速度/密度和计算压力时使用的暂态量。参考实现按实际 C 内核的顺序消元，而不是把连续吸收层公式直接替代它。此改动影响参考方程，不修改现有标签或上游生成代码。

## 研究决策、替代路线与最强反证

**继续波动方程算子方向，保留完整双参数成像目标。** 训练目标应围绕收敛波场或达到指定残差所需的计算量，不能仅以少量迭代后的通道拟合来判断方程是否解准。新网络的作用应是加速求解，而不是让未收敛误差成为输出的一部分。

衰减应作为明确的辅助物理条件处理。第一条路线是在 V5 已知局部衰减条件下训练和求双参数导数，固定 alpha(x) 与 tau；按生成器保留 `eta_j=alpha(x) c/c0 * eta_j_per_unit_alpha` 的已知解析关系，**不能把 eta 对 c 的全部导数强行设为零**。这与本轮 oracle 的成功直接对应。第二条路线是由 c/rho 预测 alpha 图，但这会额外引入 `d alpha/dc` 和 `d alpha/drho`，不再等于固定 alpha 条件下的双参数偏导数。不能只因 RF 拟合改善，就把这种附加耦合当成正确物理。单独补上已知边缘吸收区的解释已被本轮控制明显削弱。

当前最强的限制是：**即使解准现有近似方程，18 个观测合并误差仍为 0.339；真实弛豫 oracle 只在一个病例、一个频率/角度上取得近乎一致的结果。** 若后续在其他条件下使用真实局部系数、正确时钟和充分求解仍出现大失配，说明源/边界或离散物理还存在未识别问题。现有结果不能证明完整 RF 和双参数重建已经解决。

下一项最有价值的工作是：以这些收敛参考为监督或物理约束训练神经预条件器，并显式给定空间变化的 alpha 与 tau 条件；先解决求解速度和物理一致性，再评估完整 RF 和反演。暂不需要更宽网络、新一轮可辨识性试验或额外频率数据。

所有本轮诊断已结束，没有后台训练或生成任务。
