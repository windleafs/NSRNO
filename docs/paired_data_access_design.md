# 独立衰减配对与另一开发材料的数据接口

当前尚无可靠三参数图，因此本轮不生成额外数据。先修复后续真实反证所需的接口，避免仅在单一材料或组织参数共变下得到结果。

现有配对数据已保存每个材料状态的 3 MHz / 7.5 MHz 全 11 角 IQ 和原始 RF，以及独立改变衰减的材料文件。优化器只需读取观测与采集元数据；材料真值由独立生成和评价模块读取。共同材料 ID 去掉 `_hf` / `_lf` 后缀，同一 ID 可选择两种既有中心频率。

当前发散波生成器每生成一个新 ID 都重写只有该 ID 的索引，而且只能加载基础 c/rho 与 alpha 路径。修复为支持基础材料、已有配对材料或明确指定的三通道绝对材料；生成完成后保留既有索引记录，串行保护同一输出目录的共享参考。旧记录、已有 RF、采集参数与参考都不被替换。

现有基础材料的读取路径和数值保持相同。TimeAcquisition 与原始 UltraWave 复算共用只返回观测路径的查找函数；独立绘图改用单独的真值加载函数。这样后续可实际进行固定 c/rho 的衰减反证和另一开发材料的完整重建，不向优化器传入真值数组。

这里不运行新的声速/密度导数可辨识性试验，也不增加新的低中心频率，不把数据接口完成当成三参数恢复。
